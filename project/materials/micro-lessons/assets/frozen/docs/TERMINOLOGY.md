# 统一术语

规则正文见 RULES.md。表内 group 特指正交连通块，不采用某些英文材料把相近多块合称group的宽泛意义。首现用中文加英文，后续中文即可；代码仍按schema命名。

| 中文（英文） | 项目唯一含义 | 易混点 |
|---|---|---|
| 棋盘（board） | 真实完整5/9/13/19路交叉点集合 | 裁切视口不是新边界 |
| 交叉点（intersection） | 棋子所占的位置 | 不在方格内落子 |
| 棋子（stone） | 黑B、白W；空点为null | 稀疏stones省略空点 |
| 连通块（connected group / string） | 同色正交相邻的最大连通集合 | 斜邻不算连接 |
| 气（liberty） | 全块正交相邻空点的去重集合 | 共享一个空点只算一次 |
| 打吃（atari） | 某连通块恰好剩1气 | 尚未被提走 |
| 提子（capture） | 落子后同时移除相邻无气对方整块 | 在自杀检查之前；提子数不额外计面积分 |
| 自杀（suicide） | 处理提子后，新落子所在己方块仍无气 | 先提后获气可能合法 |
| 停一手／停手（pass） | 不落子，轮次交替，连续停手数+1 | 免超级劫检查、不清历史、不交子 |
| 劫（ko） | 教学先解释立即回提重现盘面 | 仍受完整位置超级劫约束 |
| 位置超级劫（positional superko） | 禁止落子完成提子后重现当前有效路径任一先前布局，含初始 | 不依赖下一手颜色；长重复也禁 |
| 终局确认（end confirmation） | 完整对弈两停后双方核对死子、中立点 | 不等于自动判死或自动结束 |
| 终局（finished game） | 完整对弈同意计分或认输后结束；小游戏按自己的终止目标 | 未完成棋局染色不是最终胜负 |
| 贴目（komi） | 开局确定、加给白方的数值；默认0、可和棋 | 教学选择，非官方小棋盘标准 |
| 面积计分（area scoring） | 活子数+己方围空；白加贴目 | 提子不重复加分 |
| 中立点（neutral point / dame） | 混合黑白边界或没有棋子边界的空区内点 | 全空棋盘也中立 |
| 眼（eye） | 有保护条件的内部空间 | 两个空点不等于两个独立真眼 |
| 真眼（true eye） | 在具体棋形条件下可靠保护的眼 | 结论须有证据范围 |
| 双活（seki） | 互相牵制而生存的情况 | 两真眼并非所有活棋必要条件 |
| 吃子小游戏（capture-first） | 首次成功提子即胜；两停无胜者 | 不以面积决定胜负 |
| 摆棋（setup） | 自由放黑白/擦除的编辑 | 不代表合法棋谱或已知劫史 |
| 新教学起点（fresh-setup） | 明示过去历史未知，经验证从此建立新历史 | 不是证明历史上未发生重复 |
| 试下（trial） | 返回候选状态，不修改提交状态 | 点击预览不等于提交 |
