# 五套围棋社微课使用说明

五套独立PPTX各5页；合并PPTX共25页，页序为落子/连接/气、提子/打吃、第一盘9×9、连接/切断、眼/简单死活。独立套文件页脚采用合并版检索页码。每套依次为引入问题、直观示例、关键对比、成员尝试、转入对弈。预计讲解6分钟，目标5–7分钟；未经真人排练。练习可继续，讲解时间不是强制计时。

## 先准备

使用 `output/T22_MicroLesson_01_r1.pptx` 至 `05`，或 `T22_All_25_r1.pptx`。所有文字、网格、棋子、坐标与标记是可编辑的原生幻灯片对象，未采用棋形截图。编辑文字可直接双击；棋子、棋盘线和三角标记可逐个选择移动。图形的坐标与题目答案绑定，修改棋形会使冻结核查失效，应修改局部源并重新验证，不能沿用旧题目ID描述不同局面。

安装随包的 `assets/fonts/NotoSansSC-Regular.ttf`（Noto Sans SC，OFL授权），再打开PPTX，避免中文替换。字体没有嵌入PPTX；不能安装字体时，先用对应PDF投影，或在PPTX中统一替换为支持中文的思源黑体/Noto Sans CJK SC并重新检查换行。PDF已嵌入字体子集，不需要额外字体。每页备注含中文短讲稿、英文术语、提问、预期回答、误解回应、转场、预计互动停顿和来源；PowerPoint“备注”或演示者视图可查，文本副本为 `source/speaker-notes.md`。不要把教师备注和备课摘要投到成员屏幕上。

材料默认按中学生、约45分钟活动、两人共用棋盘安排，可按实际情况调整。投影加实体棋盘即可使用；成员手机/平板是可选。允许跳过已经掌握的内容或直接对弈。没有成绩榜、连续打卡惩罚或以胜率评价个人价值的要求。

## 课堂顺序

先显示题面，让成员解释，再由教师按备注核对。五套第四页都保留题面，答案只在教师备注/备课摘要。第一、二、四、五套引入题的答案在后续示例中揭示。第三套使用完整5×5教学计分假设，不声称它是已收完的实战。完整对弈默认9×9、开局贴目0、允许和棋；0贴目是教学选择。双停进入共同确认，争议保留原盘与历史继续下。提子数不额外计面积分。吃子小游戏首个成功提子者获胜，双停无胜者，不用面积计分。

图中坐标列从左到右，跳过I；行从下到上。完整5×5、9×9均画出真实全部边界；没有裁切图。三角标记在目标棋子上，虚线气环在空点上；变化图棋子上的数字是该变化分支中最后一手的步数。颜色是辅助，黑白、形状、虚线与文字可在灰度中区分。摆棋题从明确新教学起点建立历史，不伪造未知劫史；立即回提演示需从KO-BEFORE合法走黑D3，不能直接把KO-AFTER摆成空历史对局。

## 低成本打印

成员用幻灯片PDF打印即可，备课摘要另有5页A4 PDF。用普通80–100g/m² A4纸，不需特定品牌。幻灯片PDF页面为16:9（约338.67×190.50毫米），选A4横向、每张一页、“适合可打印区域”，居中且不裁切；灰度可用。不选100%原尺寸，否则A4会裁切。若打印机有5毫米边距，最大图面约287×161.44毫米，实际比例约84.74%；以打印机可打印区域为准。备课摘要为A4竖向210×297毫米，选100%实际尺寸，无需裁切。打印后的大小、纸面阅读与现场投影效果尚待实体试验。

## 输入版本与可编辑制作源

依据 `GO-CLUB-FREEZE-B-20260919-01`、主线0.15.1、T09正式内容0.2.0-t09.1、T20材料0.2.0-t20.1，所用题目与图形均revision 1。`assets/frozen/`保存实际用到的只读原件副本、冻结清单、规范和原版引擎。原件未修改。`source/lessons.json`、`diagrams.json`、`combined.presentation.json`、讲稿Markdown与生成脚本均可编辑。材料JSON是T22局部制作格式，不是可直接导入正式题库的ContentBundle。`source/rendered-board-manifest.json`给出30个棋盘实例的来源、分支和坐标；见 `assets/source-index.json` 的SHA256。`source/teacher-summary.md`可编辑5页摘要内容。

## 复现

在一个空的独立工作目录中解压材料增量包，保留已有成品作参考。使用Codex主运行环境（Artifact Tool JavaScript、Python reportlab/pypdf/Pillow/fontTools、LibreOffice和Poppler），按 `source/rebuild.sh` 复现到 `materials/micro-lessons/build/reproduction/`。脚本不安装共享依赖，不更改权威输入。原始输入全量哈希复核的实测证据见 `qa/freeze-lock-check.json`；若要重新执行对所有冻结文件的558条记录核对，提供同版完整项目副本后运行 `source/prepare-assets.py`，其默认读取 `build/inputs/full/go-club`，仅更新本目录副本。主线重新冻结后必须重新核对与生成；不能只替换题图。

## 检查与限制

数字材料已完成逐页结构、备注、字号、棋子坐标和渲染检查。六个PPTX由LibreOffice Impress无界面模式实际打开并导出PDF；每个最终页面均渲染，独立版与合并版对应25页的文字、棋形及备注一致；像素对比中23页完全一致、2页仅有少量字形边缘抗锯齿差异。实际PowerPoint/Google Slides交互、真实教室投影和打印尚未测试。未进行人类教师审稿、学生实施、实体制作或真人计时；不存在活动效果或CAS工时数据。详见 `qa/QA.md` 和 `handoff/T22.md`。

增量包只包含 `materials/micro-lessons/` 与 `handoff/T22.md`。它基于冻结B 0.15.1可直接加入主线，不能用作整项目覆盖包。不修改程序、正式题库、共享依赖或根文档。
