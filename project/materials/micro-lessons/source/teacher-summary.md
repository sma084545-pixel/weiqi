# 五套微课备课摘要


## 1 落子、连接与气

目标：把棋子放在交叉点；辨认正交连接；数出整块不重复的气。

准备：两人共用棋盘、黑白棋子，教师设备与投影可选；默认中学生、约45分钟是可调整假设。

预计讲解6分钟，未经真人排练；动手可继续。


1. **引入问题，这颗黑子有几口气？**（预计50秒，互动20秒）

提问：E5周围哪些空点直接相邻？斜角算吗？
核对与回应：E6、D5、F5、E4共4气；斜角不算。可能把8个周围点全算进去。

回应：先让成员指出点位，再问“从黑子出发，沿一条线能直接到这个点吗？”不以答得快评价成员。


2. **直观示例，沿线相邻的空点才是气**（预计80秒，互动20秒）

提问：为什么斜角空点没有画环？
核对与回应：它与黑子不正交相邻；可能认为距离近就算。

回应：沿棋盘线逐个比对。提示环画在空点，目标三角画在棋子上，两者含义不同。


3. **关键对比，靠得近，连成一块了吗？**（预计80秒，互动20秒）

提问：这里有几颗黑子、几个黑连通块？
核对与回应：3颗、2块。可能把斜邻也当实连。

回应：请成员用手指沿已有同色棋子走，不能斜着跳，也不能跨空点。


4. **成员尝试，同一个空点，算几次？**（预计100秒，互动60秒）

提问：C4同时邻接两颗黑子，是否要算两次？全部气在哪？
核对与回应：C4只算一次。B5、A4、C4、A3、D3、B2、C2，共7气。

回应：在成员尝试后逐点读出7个坐标。若重复计C4，就把同一个点圈一次，再查漏点。


5. **转入对弈，两个人，轮流摆与找**（预计50秒，互动10秒）

提问：你打算先练单子，还是整块数气？
核对与回应：两种都可以，也允许直接对弈或观察。可能把自由摆子当成合法棋谱。

回应：进入按规则对弈前确认盘面、轮次；从明确的新教学起点开始，过去历史未知，不编造劫史。


讲解后：两人用完整5×5练习盘交替摆单子和相连棋子，伙伴逐点指出气。可改用9×9或直接对弈。

规则提醒：同色上下左右才算连通；整块的气为去重空点。摆棋可以任选颜色，与合法轮流对弈分开。

版本与来源：冻结点B 0.15.1；T09 0.2.0-t09.1，T20 0.2.0-t20.1，全部使用revision 1。完整逐页讲稿、英文术语、扩展问题与来源见 speaker-notes.md 和各PPTX备注。


## 2 提子和打吃

目标：认出一气的整块；预测提子；理解先提子后查己方气；区分吃子小游戏。

准备：两人共用棋盘、黑白棋子，教师设备与投影可选；默认中学生、约45分钟是可调整假设。

预计讲解6分钟，未经真人排练；动手可继续。


1. **引入问题，黑先，这一手能提白吗？**（预计50秒，互动20秒）

提问：C3白棋只剩哪一气？黑该下在哪里？
核对与回应：唯一气D3；黑D3提白。可能选D4，只因它看起来也很近。

回应：把白子上下左右逐点检查，三个位置已有黑子，只有D3为空。先接受理由，再进入演示。


2. **直观示例，一气叫打吃，无气就提走**（预计80秒，互动20秒）

提问：被打吃和已经被提走，有什么区别？
核对与回应：打吃还有1气、仍在盘上；提子是无气后移走。

回应：请成员先预测移走几颗，再用演示后的完整棋盘核对。数字1表示这次落子，不是气环。


3. **关键对比，没有外气，就一定不能下吗？**（预计80秒，互动20秒）

提问：为什么不能在提子前就判黑A5无气？
核对与回应：落子会先提掉两个白块，随后己方获得2气。

回应：按顺序实际移子，再数黑A5的气。无效动作不改变棋盘、轮次或历史；此例也由同一引擎核查重复限制。


4. **成员尝试，这一手会移走几颗？**（预计100秒，互动60秒）

提问：黑落哪里，能在本手提掉两颗目标白子？
核对与回应：D5；提2颗。D4没有填掉最后一气。

回应：在成员尝试后揭示D5，整块同时提走。若下D4，白D5可以连接扩展，这是题库已覆盖回应。


5. **转入对弈，开始一轮吃子小游戏**（预计50秒，互动10秒）

提问：第一次提子后，我们继续算面积吗？两次停手呢？
核对与回应：小游戏首提即胜；双停无胜者，不计算面积。

回应：先让两人复述本轮结束方式。落子合法性仍包含自杀与位置超级劫，不因小游戏而取消。


讲解后：两人用5×5玩明确标示的吃子小游戏：首提即止，双停无胜者，可交换颜色重开。

规则提醒：先提对方无气块，再检查己方气，再检查重复；吃子小游戏首提即止，不用面积决定胜负。

版本与来源：冻结点B 0.15.1；T09 0.2.0-t09.1，T20 0.2.0-t20.1，全部使用revision 1。完整逐页讲稿、英文术语、扩展问题与来源见 speaker-notes.md 和各PPTX备注。


## 3 完成第一盘9×9

目标：分清小游戏与完整围棋；双停后共同确认；按面积计分；理解劫与争议继续下。

准备：两人共用棋盘、黑白棋子，教师设备与投影可选；默认中学生、约45分钟是可调整假设。

预计讲解6分钟，未经真人排练；动手可继续。


1. **引入问题，提得多，就一定赢了吗？**（预计50秒，互动20秒）

提问：小游戏和完整围棋，是否都由提子数决定胜负？
核对与回应：不是。小游戏首提即胜；完整围棋算活子加围空，提子不额外加分。

回应：尝试后说明：本例黑8活子+2围空=10，白13活子+2围空=15，白多5。反事实账本不参与加法。


2. **直观示例，双停后，一起确认再计分**（预计80秒，互动20秒）

提问：两次停手后，老师可以直接把看起来死的棋拿走吗？
核对与回应：不能自动判死；需要双方确认，争议恢复。

回应：争议时保留原盘和重复历史，按原轮次继续；连续停手数归零。由争议方实际演示，不能越过轮次。停手不交子，没有白必须最后下。


3. **关键对比，白方能立即回提吗？**（预计80秒，互动20秒）

提问：白C3回提后，黑白棋子布局与哪张图相同？
核对与回应：与左图相同，因此返回SUPERKO；可能认为停一手就能解除。

回应：本项目一次落子完成提子后，若与有效路径任一先前布局相同就禁，包括初始布局。只比较棋子，不依赖下一手颜色。长重复也禁。停手免重复检查但不清历史，双停后的恢复也保留历史。完整边界见T20补充规则卡和RULES R3–R4。


4. **成员尝试，活子、围空、中立，怎样数？**（预计100秒，互动60秒）

提问：双方各有多少活子、围空与中立点？
核对与回应：黑8活子+2围空=10；白8活子+2围空+0=10；A3–E3共5中立点。

回应：成员尝试后逐项核对：8+8+2+2+5=25，覆盖全部交叉点。提子不再加分。不要把本教学假设说成已经证明这些一眼形自然活或已收完。


5. **转入对弈，完整9×9，从空盘开始**（预计50秒，互动10秒）

提问：有人第一次提子后说“我赢了”，这盘应该结束吗？
核对与回应：完整围棋仍继续；只有吃子小游戏首提即止。

回应：让双方复述模式和贴目。未完成棋局染色只能叫预览，不能报可靠最终胜负。规则细节可在对弈中按需要查T20卡。


讲解后：默认完整9×9、开局贴目0；双停后一起核对死子与中立点，有争议恢复原盘继续下。

规则提醒：双停只进入确认，不自动判死。争议保留原盘与重复历史继续下；落子后任何旧布局重现都禁止，停手豁免且不清空历史。0贴目、允许和棋是教学选择。

版本与来源：冻结点B 0.15.1；T09 0.2.0-t09.1，T20 0.2.0-t20.1，全部使用revision 1。完整逐页讲稿、英文术语、扩展问题与来源见 speaker-notes.md 和各PPTX备注。


## 4 连接与切断

目标：看出正交连接点，比较接上与被阻断后的连通块；保留多种成功接法。

准备：两人共用棋盘、黑白棋子，教师设备与投影可选；默认中学生、约45分钟是可调整假设。

预计讲解6分钟，未经真人排练；动手可继续。


1. **引入问题，黑先，一手把两块接起来**（预计50秒，互动20秒）

提问：黑在什么点，能同时正交接上B3与D3？
核对与回应：C3。可能选C2，因为在两块中间下方。

回应：先用手指沿已有棋子追连接；尝试后才揭示C3。


2. **直观示例，接上以后，作为整块看气**（预计80秒，互动20秒）

提问：连接以后还能把中间一颗当独立棋块数气吗？
核对与回应：不能，三颗属于同一块。

回应：请成员顺着黑棋走一遍连通路径。强调本页只验证这一次连接，不声称最优策略或活棋。


3. **关键对比，接上，还是被占住连接点？**（预计80秒，互动20秒）

提问：右图白C3后，原来的两个目标是不是同一连通块？
核对与回应：不是；黑C2也没有直接接上两目标。可能把这一手没接上说成永久分离。

回应：检查当前连通关系即可。后续策略仍要继续试下；不要把有限题目目标扩写成全盘胜负。


4. **成员尝试，斜邻的两子，怎样接上？**（预计100秒，互动60秒）

提问：有哪些一手接法？
核对与回应：C4或B3，两手都成功。

回应：尝试后分别摆C4、B3核对。其他合法手若未在库中收录，不因缺记录自动判错；只检查本手是否达到明确目标。


5. **转入对弈，落子前，先听伙伴的回应**（预计50秒，互动10秒）

提问：你的候选点改变了哪两块的连接？对手有什么回应？
核对与回应：允许多种有理由的选择，不评“个人价值”或快慢。

回应：先听解释，再按合法性实际试下。提出切断点不等于策略已证明最优。


讲解后：在9×9对弈中，一人提出想连接的两块，另一人先指出回应；可转5×5复摆例题。

规则提醒：本手连接只达成即时目标，不保证永远安全。未收录候选手不能自动判错；先看理由，再用合法实下核对。

版本与来源：冻结点B 0.15.1；T09 0.2.0-t09.1，T20 0.2.0-t20.1，全部使用revision 1。完整逐页讲稿、英文术语、扩展问题与来源见 speaker-notes.md 和各PPTX备注。


## 5 眼和简单死活

目标：辨认有可靠保护的独立真眼；用提子顺序识别给定假眼；在明示条件下做眼。

准备：两人共用棋盘、黑白棋子，教师设备与投影可选；默认中学生、约45分钟是可调整假设。

预计讲解6分钟，未经真人排练；动手可继续。


1. **引入问题，被黑棋围住，就一定是眼吗？**（预计50秒，互动20秒）

提问：白C3是不是一定自杀？目标黑子各剩哪一气？
核对与回应：白C3合法，先提C4、B3、D3三颗，得到气；可能认为被黑包住就不能下。

回应：先听预测，下一页用提子后的准确棋形核对。


2. **直观示例，假眼：眼壁会先被提走**（预计80秒，互动20秒）

提问：为什么白C3不是自杀？哪些黑子移走？
核对与回应：先提三目标，再得到气；下方C2黑子不在本手被提的目标内。

回应：请成员按三个目标逐个核对，不能把四个邻接黑子全部随意移走。


3. **关键对比，两个空点，还是两个独立真眼？**（预计80秒，互动20秒）

提问：两个空点与两个独立真眼，差在哪里？
核对与回应：要看空间是否独立、眼壁是否可靠保护；数量为2不足以证明。

回应：只把两受保护独立真眼作为基础充分活形。没有两眼不自动等于死，双活等情况存在。不用数据库标签作通用死活裁判。


4. **成员尝试，黑先，怎样做出两个独立眼？**（预计100秒，互动60秒）

提问：黑选哪一点，剩下哪些眼？
核对与回应：黑B5；A5、C5分开，各由同一目标黑块保护。

回应：尝试后揭示B5。黑A5留下B5、C5相连，本手未达到目标；不把“未达即时目标”直接泛化成所有局面的死亡。


5. **转入对弈，先解释眼形，再回到对弈**（预计50秒，互动10秒）

提问：遇到没见过的棋形，可以只凭“没有两眼”判死吗？
核对与回应：不能。要看具体条件与合法变化，证据不足保留未知。

回应：把“我看到了什么、还不确定什么”当作正常表达。没有强制过关、计时或胜率价值评价。


讲解后：两人复摆LIFE-003并先讲理由；再继续9×9，熟练成员可自选13×13或扩展题。

规则提醒：可靠保护的两个独立真眼是基础活形，活棋还有双活等情况。主线只验证给定局面的有限目标，不宣称通用死活证明。

版本与来源：冻结点B 0.15.1；T09 0.2.0-t09.1，T20 0.2.0-t20.1，全部使用revision 1。完整逐页讲稿、英文术语、扩展问题与来源见 speaker-notes.md 和各PPTX备注。
