# 字体说明

PDF 生成使用系统的 `Arial Unicode.ttf`，所用字形嵌入 PDF。生成器按以下顺序查找：

1. `/System/Library/Fonts/Supplemental/Arial Unicode.ttf`
2. `/Library/Fonts/Arial Unicode.ttf`

SVG 使用字体族 `Arial Unicode MS, PingFang SC, sans-serif`，打开 SVG 的设备可能替换字体。若发生替换，须重新检查标题、题干和长条件的换行；不要把替换后的视觉结果称为仍与本次冻结哈希一致。

最小常规印刷字号约 7.5 pt，只用于边界/验证说明；卡片主要题干为 11 pt，提示和答案为 8.2-10 pt。成品卡约 A5 横向；未为塞入内容而缩成微型单卡。
