# 来源与原创边界

访问日期：2026-09-06。

## 实际使用的外部页面

1. British Go Association, “Teaching Beginners”: https://britgo.org/organisers/handbook/club4
   - 用于核查一般教学建议：尽快让新手开始下棋、初局使用 9×9、纸板与计数片可构成入门器材。
   - 没有把该页对段位、让子或活动效果的说法写成学校事实。
2. British Go Association, “How to Play”: https://www.britgo.org/intro/intro2.html
   - 用于核查一般概念：棋子落在交叉点；正交相邻构成连接；气是正交相邻空点；可在 9×9 学习后扩展到 13×13。
   - 该页使用的提子计分、贴目和劫规则没有混入本项目规则。
3. British Go Association, “Our Interpretation of AGA Rules”: https://www.britgo.org/rules/bgainterpretation.html
   - 仅用于确认不同规则体系对落子、重复和小棋盘贴目的处理可能不同，因此本项目必须显式标注自定义规则。
   - 本材料没有冒称采用 AGA、BGA、中国或日本正式竞赛规则。

## 原创内容

本目录中的中文说明、毫米版式、SVG/PDF 生成代码、校准尺、收纳标签、借还清单、便携包示意、覆片提示和几何测试均为本次 T19 原创实现。棋盘线和坐标由代码按固定数值生成，不由生成图片猜测。导航点只作为本材料的视觉定向辅助，不声称是任何规则体系的官方小棋盘标准。
