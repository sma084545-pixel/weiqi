# 尺寸、纸张与裁切

A5卡148×210 mm；A6小卡105×148 mm。建议普通80–120 g/m² A4纸先试印；较耐用版可用打印机允许的160–200 g/m²纸，或把两张薄纸背靠背粘在旧薄卡纸上。材料：纸、直尺、铅笔、剪刀/裁纸工具；胶水与透明保护套可选，不要求品牌。未进行实体制造或学生试用。

打印选“实际大小/100%”，关闭“适合页面”、多合一及小册子排版。PDF已经拼版。正文10–12 pt，图题/脚注另有较小字号；不要为节纸再缩版。灰度可印，黑实心子、白空心大子、小气环、三角落点与×中立点靠形状区分。页面上方色条允许打印机留白，不影响内容；正文距裁边至少约10 mm。

A5拼版：A4横向297×210 mm，双面“短边翻转”。每一对页面是同一张纸的正反面；左右各放一张相同卡。纸张从左边或右边翻过去，字仍正立。左卡x=0.5至148.5 mm，右卡x=148.5至296.5 mm；先在x=148.5 mm中线裁开，再各裁外侧0.5 mm。用直尺在上下纸边做记号后裁切；不按色条猜尺寸。

A6拼版：A4纵向210×297 mm，双面“长边翻转”。每页四张同面小卡；从左边或右边翻页，字仍正立。竖裁线x=105 mm；横裁线从纸顶计y=148.5 mm；裁去顶部与底部各0.5 mm。每张成品105×148 mm。

先只印第1–2页做双面样张：核对上下方向及脚注配对号。自动双面机的驱动命名可能不同，应以“从左/右翻过去，两面字都正立”为验收。手动双面时先在废纸一角画箭头，测试打印面、进纸边与朝向，再印正面/背面；不要盲用通用翻纸口诀。若驱动无法对准，可分别单面印正反并背靠背粘合。实体套准偏差、纸张厚度适配与裁切安全待使用者实测。

# 教师使用说明：规则准确性

默认中学生、每次约45分钟、两人共盘，仅是可调整设计假设；未确认学校年龄、设备、人数或预算。可先用主卡演示约5–8分钟，再自由选择操作；没有强制计时。只有投影时，按显示坐标口述，成员可在实物盘指出落点；手机不是参与前提。

1. 空盘黑先。图示都是完整5×5小棋盘练习，上方5行、左侧A列，不是裁切局部。数据row/col从0开始，row向下，显示行反向。大盘列A–T跳过I；支持完整5/9/13/19路，初学完整对弈默认9路。图下短码加前缀RULE-DEMO-T20-即为JSON文件ID。
2. 同色正交相邻才是一块；同一空点只算一次气。一气是打吃，零气才提整块。落子先检查轮次/坐标/占用，暂放己子，同时提完相邻无气敌块，再查自己的气，最后查重复。无效动作不改任何状态。三角不是棋子，小环不是白子。
3. 劫图左→右：黑D3提白C3；白C3立即回提将重现左图，禁止。完整位置超级劫只比较本局当前有效路径上棋子布局，含初始，不依赖下一手颜色；更长重复也禁，不能说“等一手一定能提”。停手免检查但不清历史。摆棋起点的过去未知；验证局面/轮次后建立新历史，不能声称旧局没出现过此形。
4. 完整对弈两停进入终局确认。没有停手交子，也不要求白最后停手。死子以完整同色块共同确认；不自动判死。计分移除只是副本，原盘和提子记录不变。中立点按移除死子后的空区判断：混合黑白边界，或无棋子边界的空区均中立，全空棋盘也中立；不能随意把己方围空改成中立。有争议恢复原盘、轮次与重复历史，停手数归零，清除预览标记；争议方按现有轮次实际演示，另一方可合法停手，不直接抢先。仍无共识则保留未解决，不能硬判结束。
5. 计分卡是从T00 docs/RULES.md 的 DEV-END-001 改编的明确教学假设，另用RULE-DEMO-T20-SCORE标识，原ID原数据不变。盘上黑白各9子，各围1空；中央5点边界混合。9+1=10；9+1+0=10；18+2+5=25。即使过程记录黑提7、白提2，也仍10:10，不是17:12。只有另开算例预先设贴目0.5时，白为10.5；不在同局中途改贴目。该形有一眼的部分，不作为无条件活棋或自然终局的证明；原引擎按teaching-assumption计算，不冒称confirmed。
6. 两个可靠保护的独立真眼是基础活棋形，不等于两个空点，也非所有活棋必要条件。初学死活选择无劫、无双活、无外部征子依赖的已核查材料，说明先手、目标、边界与条件；没有正式题库时不假造题目或判定未收录着法错误。
7. 路线与CURRICULUM六阶段一致；阶段02含“打吃提子→吃子小游戏”两个小步骤，阶段03完整9路在阶段05深学死活之前。可跳过、重访、直接下棋或旁观。勾选只是自我表达，可留空；不作证书、等级考试、公开成绩榜、连签惩罚或胜率评价。

# 编辑、字体与再生

PDF嵌入本机STHeiti Light的所用字形；系统字体文件不随包再分发。SVG保留可编辑文字，优先Heiti SC，可替换为有合法使用许可的Noto Sans CJK SC/思源黑体。替换会改变字宽，须再生成/逐页复查。环境变量T20_FONT可指定支持中文且可嵌入的TTF或TTC；仅自行获得字体，不自动安装或购买。

源代码不含第二套围棋引擎。Node脚本直接导入 ../../../dist-engine/go-club-rules.mjs；独立增量包应用到0.2.0工程后即可运行。Python生成依赖reportlab、pypdf；验证需Pillow和pdftoppm，详见validation/ACCEPTANCE.md。JSON中的Position完全沿用schemaVersion=1；diagram-index和card-manifest是材料局部索引，非正式ContentBundle，不应直接交给正式内容导入器。正式程序未来按资源ID加载Position并标示fresh-setup，无过去棋史。
