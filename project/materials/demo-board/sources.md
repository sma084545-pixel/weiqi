# T18 资料与证据边界

访问日期：2026-09-06。

1. British Go Association, “Teaching Beginners”: https://britgo.org/organisers/handbook/club4
   - 本材料只采用其“一开始保持简短、用演示盘或投影、让新手尽快在 9×9 上动手”的教学方向。
   - 这是外部教学建议，不是本社团已取得的效果，也不是本项目的参与门槛。
2. British Go Association, “How to Play”: https://www.britgo.org/intro/intro2.html
   - 用于交叉核查交叉点落子、正交连接、气，以及单子在中心/边/角分别有 4/3/2 气的一般概念。
   - 该页的计分、贴目、劫和终局表述不覆盖本项目规则。
3. British Go Association, “Our Interpretation of AGA Rules”: https://www.britgo.org/rules/bgainterpretation.html
   - 仅用于确认不同规则体系对术语和重复局面的处理可能不同。
   - 本教具始终遵循项目自定义规则 `GO-CLUB-AREA-1`；没有把该页的 AGA 解释混入项目规则。

棋盘图、标记图、两组摆棋流程、尺寸系统、装配表达与生成代码均为本任务原创。规则定义来自项目 T00/T01，题目库未参与本任务，因此没有创建或复用正式题目 ID。
