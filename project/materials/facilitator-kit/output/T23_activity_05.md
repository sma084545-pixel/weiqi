# 合作挑战

说清选择的目标、可能回应与代价，给同伴解释机会。

器材与布置：G＝⌈N/2⌉。每组 B9/B5 各 1 盘、黑白各 90 子、1 份规则卡、2 支笔，所选题卡各 1 套。 13 路可选：每组加 B13/B13T、各色 180 子；无大盘继续 9 路。 可设最多四站：找气、提子、救棋、讨论。每站至少一盘；人数少就同桌换卡，允许留在原站。

微课：T22_MicroLesson_04_r1.pptx 第 4–5 页（合并第 19–20 页）；T22_MicroLesson_05_r1.pptx 第 5–5 页（合并第 25–25 页）

题卡均 r1，括号为正/背页→答案页：DISC-001（13→29）；DISC-002（14→30）；DISC-003（14→31）；DISC-004（15→32）；DISC-005（15→33）；CON-003（7→16）。

开场：作者参考不是唯一答案。一人提出计划，一人找回应，然后换角色；改变想法也可以成为交流内容。

| 时段 | 主持与成员动作 |
| --- | --- |
| 0–3 分 | 选题与分角色：自选 DISC 一题，A/B/自提落点均可。 |
| 3–6 分 | 短提示：回看关系与回应，留一句话给新手。 |
| 6–23 分 | 比较两手：先说目标和预期回应，交换角色后共同修订，再看参考。 |
| 23–39 分 | 任务站或对弈：选合作救棋或另一张讨论卡，也可直接对弈。 |
| 39–42 分 | 分享一个观察：只记录说出的理由、回应或修改，不评能力。 |
| 42–45 分 | 反馈与整理：自愿反馈；讨论记录保存前让双方预览。 |

- 零基础：选 DISC-001 的一个候选，解释一句，并听一个回应。
- 少量经验：在 DISC-002/004 说出舍弃或提子的代价。
- 熟练成员：可选完整 13 路 DISC-003 的更深回应；无大盘则选其余 9 路题。

无屏：纸上写“目标—计划—可能回应—修订”，同号卡背在初次表达后翻开；讨论可以口述，不要求填写全部字段。

结束问：你能准确复述伙伴的计划吗？哪个回应让你保留或改变了原想法？

收尾：自愿三项反馈或跳过；活动编号/日期按实际填写，之后清点收纳。

注意：DISC 五题均为开放讨论，不自动判文本对错。任务站不是速度赛；角色约定不是官方 Pair Go 赛制。
