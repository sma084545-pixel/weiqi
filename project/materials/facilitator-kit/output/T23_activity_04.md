# 眼的探索

比较真眼、假眼以及两个空点与两个独立眼，知道结论有条件。

器材与布置：G＝⌈N/2⌉。每组 B9/B5 各 1 盘、黑白各 90 子、1 份规则卡、2 支笔，所选题卡各 1 套。 先将卡背朝下；完整题盘与自由对弈盘分开标记。伙伴只在取得同意后移动对方棋子。

微课：T22_MicroLesson_05_r1.pptx 第 1–5 页（合并第 21–25 页）

题卡均 r1，括号为正/背页→答案页：LIFE-001（8→19）；LIFE-002（9→20）；LIFE-003（9→21）；LIFE-004（10→22）；LIFE-005（10→23）。

开场：我们先问对方能不能合法落在这个点。你可以先猜、看一手，或者直接选择对弈，不需要通过死活考试。

| 时段 | 主持与成员动作 |
| --- | --- |
| 0–3 分 | 选择与预测：指明目标棋块、先手及想验证的点。 |
| 3–9 分 | 短微课：看第 5 套，在答案页出现前保留猜测。 |
| 9–23 分 | 对照探索：先试 LIFE-002，再比 LIFE-001/005；按需试 LIFE-003/004。 |
| 23–38 分 | 自由对弈或重试：返回对弈，或隐藏提示从原卡起点再试。 |
| 38–42 分 | 说清条件：指出眼壁、独立空区及当前轮次，保留未知。 |
| 42–45 分 | 反馈与整理：自愿反馈并恢复示意盘。 |

- 零基础：只比较 LIFE-001 与 LIFE-002，允许口述或圈点。
- 少量经验：LIFE-003 黑先与 LIFE-004 白先分别摆原卡，比较关键点。
- 熟练成员：解释 LIFE-005 的已核查变化与证据范围；未知分支请同伴试下。

无屏：把原卡完整布局、目标三角和先手摆出，先口述再按已核查分支逐手演示；未经核查的自创变化只作讨论。

结束问：眼壁是否同属可靠保护的棋块？两个空点为什么不一定是两眼？

收尾：自愿三项反馈或跳过；活动编号/日期按实际填写，之后清点收纳。

注意：不只切换颜色标签来改变先手。两个受保护独立真眼是基础活形，缺少两眼不自动死亡；双活存在，本次不作复杂双活训练。
