# 成员共创与自由对弈

试做一份观察任务或解释一手，留下真实可核查的修订问题。

器材与布置：G＝⌈N/2⌉。每组 B9/B5 各 1 盘、黑白各 90 子、1 份规则卡、2 支笔，所选题卡各 1 套。 13 路可选：每组加 B13/B13T、各色 180 子；无大盘继续 9 路。 创作区一盘、对弈区其余盘；每组仍有棋盘。没有个人设备就用纸笔，教师设备只负责可选录入。

无必看新微课；可按需回看 T22_All_25_r1.pptx。本次以创作、交流和对弈为主。

题卡均 r1，括号为正/背页→答案页：LIB-001（1→4）；LIB-004（2→7）；CON-003（7→16）；DISC-001（13→29）。

开场：今天可以写一个问题、解释一个棋形，或继续下棋。纸稿也算创作草稿；我们先让伙伴试，再决定改哪里。

| 时段 | 主持与成员动作 |
| --- | --- |
| 0–3 分 | 自选任务：选共创、同伴讲解或自由对弈，可中途换。 |
| 3–7 分 | 说明草稿边界：参考正式题但不改原题号；新稿用新的本机/纸稿编号。 |
| 7–20 分 | 创作或第一段对弈：写目标、先手、完整盘边和条件；不确定答案标待核查。 |
| 20–38 分 | 伙伴试用或继续对弈：先听伙伴哪里不清楚；可修订，或继续所选对弈。 |
| 38–42 分 | 交流与记录：记录实际修改和贡献，未试用就写未观察。 |
| 42–45 分 | 反馈与保存：自愿反馈，存纸稿或本机草稿，再清点。 |

- 零基础：借 LIB-001 的方式提出“找哪块的气”，可只口述目标。
- 少量经验：参考 LIB-004/CON-003 做一份独立草稿，让伙伴试一手。
- 熟练成员：用草稿编辑器核查结构与着法，或自选 13 路；不宣称通用死活证明。

无屏：写纸稿编号、目标、先手和完整盘面；作者与试用者分栏记问题与修订。也可不创作、直接实体对弈。

结束问：伙伴实际指出了什么问题？哪些结论还没验证，下次准备怎样查？

收尾：自愿三项反馈或跳过；活动编号/日期按实际填写，之后清点收纳。

注意：只修改本机或纸面新草稿，不覆盖正式题与冻结 revision。计划、修改、真实实施和实施后观察分别记录；AI 协助与同伴贡献如实注明。
