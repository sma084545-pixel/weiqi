# 程序与完全无屏替代表

两列执行的是同一目标。无个人设备、投影不可用或首次未缓存时，直接用右列完成核心步骤。

| 活动 | 程序版 | 无屏版 |
| --- | --- | --- |
| 气实验室 | 点棋块后圈气、预测再验证 | 按同号卡摆整块；指尖/纸环圈空点，伙伴去重核对。 |
| 提子实验室 | 预测后分步播放，可暂停回看 | 口述落子→查对方气→同时移走无气块→查己方气；中间帧不算真实一手。 |
| 吃子小游戏 | 首提即锁定、两停无胜者 | 纸上记本轮执色；首提立即停下，换色重开，不数面积定小游戏胜负。 |
| 完整对弈 | 两停确认、死子标记和争议恢复 | 用可移除标记；两人同意后数面积，争议拿掉注释并照原历史继续。 |
| 互动挑战题 | 分层提示、未知分支、回退 | 先看卡正面；按需求只读卡背一条提示，再用答案册看已覆盖变化；未知保留讨论。 |
| 合作挑战 | 计划者/回应者换角色，预览讨论 | 口述或写目标、回应、修订；换角色保留旧意见，先表达后看参考。 |
| 眼与数子专题 | 目标/先手、区域标记、教学试算 | 目标三角在棋子、气环在空点；按原卡先手摆；纸笔标归属，争议不判赢家。 |
| 教师草稿 | 复制为本机新稿、保存前核查 | 纸稿用新编号；写完整边界与条件。答案待核查就留空，不冒称正式题。 |
| 离线与本机数据 | 已可离线后断网刷新；完整备份 | 程序不能加载就转纸卡与实体盘；材料 PDF/PPTX 要单独预下载，纸稿收纳保留。 |
| 成员反馈 | 建立活动，提交清空，下位空表 | 一人一张自愿空表，允许全留空；分开回收，查看原文后决定可否导出。 |
