# 同伴帮助和新成员接待

## 帮助者把选择留给伙伴

- 先问“你现在想保护、连接还是提哪一块？”让伙伴自己指出目标。
- 等待对方尝试。征得同意后只给一个可观察提示，例如“沿这块外边找还空着的点”。
- 把落子选择权留给伙伴；需要演示时另用示意盘，不移动真实对局来替他下。
- 请伙伴说一个可能回应；准确复述后再提出自己的回应。
- 每次题目或一段对弈后交换计划者与回应者，允许不当讲解者。
- 回看一手、谈一个观察就够。已核查的局部成功、未知分支和整盘判断分开说。
- 不公开比较快慢、棋力或胜率；熟练成员不包办全体讲解。

## 随到随加入

问“想先看一手、找气还是直接下？”不用姓名与班级，找到愿意同行的伙伴即可。给一张规则卡、一个完整棋盘与可选择入口，介绍坐标、轮次和暂停的方法。

最短接待示范：把一颗子放交叉点，沿线指出空点叫气；下一手先由新成员自己选。需要补充提子时只演示一手。等到实际出现劫、结束争议或眼形，再给对应小提示，不把全部死活作为加入门槛。

若新成员加入正在进行的局，不擅自改盘或接管执色；先双方同意观察/接替，或者另开一局。想离开可直接结束活动，保留未完成棋局，不处罚、不要求连续打卡。
