# 连接和救棋

看见连接如何改变整块的气，区分局部救棋与永久活棋。

器材与布置：G＝⌈N/2⌉。每组 B9/B5 各 1 盘、黑白各 90 子、1 份规则卡、2 支笔，所选题卡各 1 套。 两人一盘，目标三角与气环分别放在棋子和空点；提示者坐在伙伴侧边，不接管棋子。

微课：T22_MicroLesson_04_r1.pptx 第 1–5 页（合并第 16–20 页）

题卡均 r1，括号为正/背页→答案页：CON-001（6→14）；CON-003（7→16）；CON-005（8→18）。

开场：先说你想保护哪一块，再听伙伴提出一个回应。我们看的是这一步改变了什么，不必找全盘最佳手。

| 时段 | 主持与成员动作 |
| --- | --- |
| 0–3 分 | 找目标：各选连接或救棋，指明目标棋块。 |
| 3–9 分 | 短微课：看第 4 套，先猜连接点再看变化。 |
| 9–21 分 | 合作救棋：按 CON-003 黑先，先说计划再落一手；交换计划者与回应者。 |
| 21–38 分 | 对弈或继续试形：选 CON-001/005 或自由对弈；未知合法手保留讨论。 |
| 38–42 分 | 解释一次变化：复述伙伴的目标，比较落子前后整块的气。 |
| 42–45 分 | 反馈与整理：自愿反馈，恢复题目起点与收纳。 |

- 零基础：在 CON-001 找一个连接点，用手沿同色棋子走一遍。
- 少量经验：CON-003 救出被打吃的目标，再猜对方一手。
- 熟练成员：比较 CON-005 的救棋与连接；说明局部成功的证据边界。

无屏：照卡正面摆完整 5 路题盘，口述目标和回应，轮流实际落子；用卡背/答案册核对，题目尺寸与先手照原卡。

结束问：这步接起了哪两块？救出目标一手是否已经证明永远活？

收尾：自愿三项反馈或跳过；活动编号/日期按实际填写，之后清点收纳。

注意：CON-003 只要求目标留下且至少两气；连接成功不等于整盘好棋或永久活棋。
