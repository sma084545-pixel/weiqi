# T13｜实体棋盘围地与面积数子操作卡

规则：GO-CLUB-AREA-1  
坐标：数据从左上角 (0,0) 开始；显示列 A–T 跳过 I，行号从下往上。

1. 先判断棋是否真的进入终局确认。两次停手只是进入确认；有争议就恢复对弈并实际演示。
2. 双方一起确认整块死子。把确认死子从盘上拿走；不确定的棋不要擅自删。
3. 用三类小标记覆盖所有空点：黑方围空、白方围空、中立点。沿棋盘边和角形成的围空可以计算；纸张裁切边不算棋盘边。
4. 一人按连通空区逐区标，另一人查看每个空区正交相邻的棋子边界。只接触黑棋归黑，只接触白棋归白，同时接触双方或无棋子边界为中立。
5. 分开数：黑活子、白活子、黑围空、白围空、中立点。检查这些数量之和等于棋盘交叉点总数。
6. 黑总分＝黑活子＋黑围空。白总分＝白活子＋白围空＋开局贴目。提子记录只作信息，不再加分。
7. 双方确认同一份死子和中立点清单后才写最终结果。若不同意，恢复原盘继续下。

建议分工：甲标空区，乙数活子；交换后复核。使用正式示例时同时写下 END-xxx 题号。

本卡不自动判断死活，也不是另一种数目法。正式任意棋局的争议处理使用 T08 双方确认流程。
