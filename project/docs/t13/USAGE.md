# T13 围地与面积数子使用说明

打开 #/learn/territory。六个按钮对应 T09 正式 END-001–END-006，均保持 revision 1。每题先判断当前局面应“按给定假设试算”“继续对弈”还是“先确认争议棋块”。END-001–END-005 是明确教学假设，进入试算不表示某场真实对局已经由双方确认；END-006 是 unsettled 反例，程序不生成分数或赢家。

可计分示例按题面死子清单生成练习副本。选择黑方空点、白方空点或中立点后，可以逐点标记，也可一次标完整正交连通空区；每次操作都可撤回。提交前，正确标签、分数和边界答案不进入页面。提交后逐区显示接触黑棋、白棋、双方或无棋子边界的证据，并指出漏标、混标或错归。

面积构成必须按六步展开：确认死子、剩余活子、围住空点、中立点、贴目、总分。表格只使用 T01 scoreArea 的结果，提子记录不进入公式。贴目试算重新调用同一引擎，只改变内存中的临时数值；切题或“恢复原示例”会回到正式 fixture 的贴目。

完成 END-001 和 END-005 的预测后，页面可比较相同盘面与不同提子账本。这个对比说明面积法不重复加提子，并不表示提子在实战中没有作用。没有个人设备时使用 materials/t13/territory-counting-card.md；网页下载来自同一文件。
