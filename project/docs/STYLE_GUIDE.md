# 显示与风格基础

中文为主，关键术语首次附英文，简洁、友好，不幼稚化。不使用虚构学校品牌、学生照片或统计。默认标题“围棋社”可配置。设计参考为本次ImageGen单屏概念；原生实现保证棋盘交叉点数准确，不从图片提取规则。

白底#fff、正文#18231d、森林绿#174b32/#246244、分隔#d2dbd5、棋盘#e9bd78。正文系统中文无衬线，标题用本地宋体回退；没有远程字体。桌面棋盘/控制双栏，940px以下棋盘在上，600px以下单列。无音效依赖；prefers-reduced-motion时关闭预览、焦点和滚动过渡。

关键操作有文字，坐标语音标签包含黑/白/空和可操作状态，选择与焦点有独立边框。标记用虚线环、三角、圆、数字、加号和带字方框，不只依赖颜色；灰度验证见`t02/ACCEPTANCE.md`。标准每点至少32px、投影40px；大棋盘自身滚动，禁止扩大整页视口。实体设备和专用辅助技术状态以最新验收表为准。

T03首页以一个清楚主标题、三个意图入口、连续六阶段路线和设备说明组织，不使用锁、奖杯、得分、百分比、连续打卡或装饰性仪表盘。可用入口用深绿实心操作；未安装项目用正文明确说明并只提供已可用的返回路径。桌面保留开阔横向层次，650px以下改为单列并让顶部三项导航保持可见。投影模式放大文字和边框，不显示schema、引擎名等实现信息。

T04 气实验室在预测提交前不渲染答案节点。中性演示标题不含气数；双线轮廓标整块、加号标用户圈点、虚线环标核对后的气。桌面使用棋盘/任务双栏，980px 以下上下排列；模式和演示按钮至少 48px 高。错误反馈用文字列漏选/误选坐标并给观察原因，不只用颜色或叉号。

T05 提子实验室延续白底、深绿、木色盘和宋体标题。目标用三角、候选用加号、最后一手用实心圆、气用虚线环，文字同时说明含义；四步轨迹独立于棋盘。桌面为棋盘/预测双栏，900px 以下单栏，360px 的演示按钮两列。播放期间禁用交点但保留可读状态；减少动画直接到终态。成功或错误均用文字与边框表达，不只依赖绿色、红色或动画。

T06 自由实验棋盘用顶层双模式按钮持续显示“摆棋示意/按规则试下”。当前模式和工具同时使用文字、边框、压下状态与色块；灰度下仍可辨认。桌面棋盘/工具双栏，980px 以下改为单栏，600px 以下工具两列；9/13/19 路继续在棋盘容器内滚动。非法 setup 用文字和目标形状指出，无颜色也能识别。保存、导出、两套撤回和 fresh-history 确认都写全称，不靠图标、右键或 hover。

T07 同屏双人吃子小游戏把玩法句置于标题下，当前执色同时用黑白棋形、文字和“伙伴A/B”说明。开局设置一经双方确认即锁定；悔棋使用原生模态对话框按黑、白顺序显示确认进度。结束后仍显示盘面、文字结果、最后一口气说明与最多五步回看；三角标出被提棋原位置，圆环标出获胜落点。桌面棋盘/操作双栏，980px 以下单栏；手机上的9路盘允许局部滚动。灰度与减少动画模式保留文字、轮廓和直接完成操作。
