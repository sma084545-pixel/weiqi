# T05 设计保真检查

设计参照：`docs/t05/design-concept.png`。实现截图：`output/playwright/t05/1280-initial.png`、`360-initial.png`、`1280-final-projector-grayscale.png`。概念图与最新截图均已用原始分辨率逐图查看。

| 比较点 | 设计证据 | 实现证据与处理 |
|---|---|---|
| 页面层级 | 标题→六演示→棋盘/预测→播放器→讨论 | 1280 初态保持此顺序；播放器在预测后出现，避免空占位 |
| 色彩和字体 | 白底、森林绿、木色盘、宋体标题 | 沿用 T04 token；灰度终态仍靠形状、文字和边框区分 |
| 棋盘/任务双栏 | 桌面左右并列 | 1280 双栏；768/360 自动单栏且无页面横向溢出 |
| 预测控制 | 目标选择及明确“不会提子” | 原生 checkbox/radio，均有文字标签和至少 44px 操作高度 |
| 四步控制 | 四步轨迹、前后、播放、直接完成 | 实现完整；暂停及锁盘状态在真实浏览器检查 |
| 手机布局 | 单栏、六演示紧凑排列 | 360 截图为 2 列演示、棋盘与任务顺序清楚 |
| 后续入口 | 可用棋盘练习与未接入小游戏 | 真实 registry 状态；没有把 planned 模块伪装可用 |

首屏文案对照没有新增成绩、奖励、胜率、学校品牌、学生数据或成效主张。概念中的装饰性候选点按钮组未照搬，因为实际交互允许直接点击任意棋盘点，并提供基于内容数据的建议点；这是为保持真实功能和可访问坐标。未发现需要继续修复的材料视觉偏差。
