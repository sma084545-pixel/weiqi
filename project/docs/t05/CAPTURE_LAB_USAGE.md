# 提子实验室使用说明

从学习路线第 2 阶段、教师视图或 `#/learn/captures` 打开。六个 `DEMO-CAP-*` 均为开发演示，不属于正式 30 题。

1. 选择演示并在完整 5 路棋盘点一个候选落点；也可用“建议点”。
2. 合法候选只建立 `Trial`，尚未提交。选择可能被提的目标棋，或明确选“不会提子”。
3. 按“验证我的预测并播放”。四步固定为：落子、检查对方气、移除被提棋、查看最终己方气。
4. 播放时可暂停、上一步、下一步或直接完成；棋盘锁定，不能接受第二手。
5. 到第四步时只提交一次 `trial.nextState`。结果列实际被提、漏选、误选和因果说明。
6. “撤回到动画前并重试”调用共享 `undo`；重置、换题或离开页面会卸载播放器并取消定时回调。

“减少动画”直接到已验证终态；系统 `prefers-reduced-motion` 会作为初始偏好。它不绕过合法性和预测步骤。非法点用 T01 稳定错误说明，原局面、历史、轮次和计数不变。

教师可先用 DEMO-CAP-004 接受“不会提子”，再用 005/006 对比先提后有气与真正自杀。说明应聚焦最后一口气和处理顺序，不把每次提子评价为战略好棋。页面不播放强制音效、不记分、不排名。
