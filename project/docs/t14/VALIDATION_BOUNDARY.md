# T14 检查与证据边界

自动检查覆盖：共享 schema v1 结构与引用、必填编辑字段、支持的完整棋盘尺寸、坐标/占点、`fresh-setup` 起点可运行性，以及变化树从根到每一节点的轮次和 T01 着法合法性。失败项给稳定代码和字段路径，非法变化不会写入草稿。

自动检查不覆盖：答案树是否穷尽、成功/失败结论是否充分、死活是否具有通用性、某手是否战略最佳、来源是否已由外部机构核准，或是否发生真人教学复核。界面始终写明这一边界；`modelChecked` 保持空值。

发布需要作者明确填写核查方法并勾选自报。系统将该动作记录为 `solutionChecked`，证据同时说明“编辑器未证明解答完备”。`humanReviewed` 只有使用者主动勾选并填写实际复核者和范围后才生成，字段标明自报；本交付没有声称已经发生真人围棋教师复核。

变化树中的 `unknown` 和 `unsettled` 可保存；名称不能替代证据。确定 `success`、`failure`、`verified-alive`、`verified-dead` 必须填写具体解释和证据文本。T10 对未覆盖合法着法仍返回未知，不记作错误率。
