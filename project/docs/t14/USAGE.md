# T14 教师出题编辑器使用说明

入口为教师视图中的“打开教师出题编辑器”，直接地址是 `#/teacher/editor`。这是当前设备上的工作区，不是账号权限区；能使用该设备的人都可能进入。草稿保存在浏览器本机存储，没有默认网络上传。

## 创建一题

1. 选择“新建空白题”，或从四个 `TEMPLATE-*` 开发模板开始。正式 30 题只能只读打开；编辑须“另存为副本”或“明确创建新 revision”。
2. 填写稳定 ID、列表标题、学习目标、类别、文字难度及理由、题干、完整棋盘尺寸和先手。
3. 用“放黑、放白、擦除、目标三角”编辑盘面。目标只能标在棋子上。切换尺寸会先显示裁切说明；确认后才移除超出坐标的内容，并重置变化树。
4. 填写外部条件、三层提示、来源标题与使用边界。坐标仍是左上角 `(0,0)` 的 `row,col`；界面显示列跳过 I、行从下向上。
5. 选择答案类型。数字允许编辑时暂时留空，但空值、小数和负数不能发布；点集和归属在棋盘空点上标；开放题填写量规；战术题用变化树逐手录入。
6. 运行自动检查。检查只确认结构、坐标、起点、必填字段和已录着法合法性，不证明答案完备、唯一或战略最佳。
7. 用“切换到学生预览”打开真实 T10 播放器。返回后仍是同一份草稿，预览不会保存尝试或发布内容。
8. 发布前写下实际解答核查方法并主动勾选。人类复核只有实际真人完成后才填写；留空会保持 `humanReviewed:null`。

## 变化树

根节点代表初始局面。当前节点的棋盘和轮次由 T01 从根逐手重放。点击空点或录入停手会建立子节点；选择节点或“回到上个分叉”可从任意既有节点增加另一条线。支持多个 `success`、代表性 `failure`、`continue` 和 `unknown`。确定成功、失败、`verified-alive` 或 `verified-dead` 必须写解释和证据；未知分支可以诚实保留，未录分支按 `uncoveredPolicy:unknown` 交给 T10。

## 保存、冲突和删除

- 保存使用 `{id}@{revision}` 识别内容。相同身份冲突时必须选择生成 `COPY` ID 或显式替换。
- 正式 ID 不能由空白题无提示覆盖；正式题创建新 revision 是明确操作。
- 软删除只改变本机工作区状态，可在“显示已软删除”后恢复。
- T10 只读取明确发布且 `developmentOnly:false` 的本机题；同一 ID 只使用本机最高 revision，避免与正式旧版重复显示。
- `Puzzle JSON` 和单题 `ContentBundle JSON` 可直接导出并通过 schema v1 校验。批量导入、图片和 SGF 留给 T15。

四个模板是 `TEMPLATE-LIB-001`、`TEMPLATE-CAP-001`、`TEMPLATE-LIFE-001`、`TEMPLATE-DISC-001`，仅用于创建草稿，不计入正式 30 题，也不带人类复核结论。
