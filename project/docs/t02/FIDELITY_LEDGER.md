# 设计参考与成品核对

参考图为 `docs/t02/design-concept.png`，最终桌面截图为 `output/playwright/t02/1280-select.png`，移动端19路为 `360-19-scroll.png`，灰度标记为 `1280-markers-grayscale.png`。参考图仅指导界面构图，不是实现或规则证据。

1. **整体结构**：保留棋盘左、控制右、上方简洁标题的桌面结构；768px改成棋盘上、双列控制，360px改成单列，避免照搬桌面比例。
2. **视觉语言**：保留白底、深绿细线、暖木棋盘和宋体标题；成品减少参考图的装饰棋子，优先展示可读状态与实际命中区。
3. **棋盘几何**：参考图误将9路第9列写为 I；成品按共享坐标改为 J，并以 N+N SVG 线和 N² 交点实现真实几何。
4. **操作语义**：参考图示意文字把占用黑子写成“可落”；成品区分空点可落、棋子占用不可落、显式不可用，并由 T01 引擎提交落子。
5. **标记与控制**：六类标记、四种模式、尺寸、坐标、投影、缩放和复位均实现；成品增加统一状态区、键盘返回和说明文字，满足实际验收。

逐图人工检查：桌面布局无裁切，棋子中心在线交点；移动端页面无横向溢出且19路只在棋盘区域滚动；灰度图中黑白棋、三角、虚线气环、圆形最后一手、数字和带字区域仍能区分。此检查由本助手完成，不是人类教师、学生或真实设备测试。
