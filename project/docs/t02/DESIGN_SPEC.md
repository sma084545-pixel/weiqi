# T02 视觉与交互规格

设计概念：`docs/t02/design-concept.png`，由本次基于 T00 `docs/design-reference.png` 生成，仅用于界面布局与视觉比较，不是课程截图、棋题、活动照片或规则证据。

页面采用 T00 的纯白背景、森林绿、暖木棋盘、宋体主标题、无衬线控件和细分隔线。首屏只有项目页眉、标题与“开发示例，不是正式课程”、一个主要棋盘工作区和右侧控制栏；不增加成绩、课程完成状态、学校品牌或效果宣称。桌面为棋盘与控制栏两栏，窄屏自然改为一栏。

组件族只有分段选择、尺寸选择、坐标/投影开关、缩放与复位、棋盘、操作说明和标记图例。控件用原生 button、radio 或 checkbox；所有可见文字由 HTML 渲染。棋盘用代码绘制 N 条横线、N 条竖线与 N² 个交点，不使用概念图作为实际棋盘。

| 项目 | 实施值 |
|---|---|
| 页面背景 / 文字 | `#fff` / `#19251f` |
| 主要强调 / 深色强调 | `#23583d` / `#153f2c` |
| 棋盘 / 棋线 | `#edc585` / `#4f3b20` |
| 次要线 / 弱文字 | `#d7ddd9` / `#526058` |
| 圆角 | 控件 6px，棋盘 8px；不采用大面积卡片圆角 |
| 动效 | 仅 hover/focus 状态，不依赖动画；reduced-motion 明确关闭过渡 |
| 容器 | 白底开放式工作区，棋盘与控制栏之间用一条绿线分隔 |

标记叠放从低到高：区域底色 → 棋线 → 候选点 → 棋子 → 气环 → 目标三角 → 最后一手 → 数字顺序 → 焦点/选中轮廓。数字用偏角小圆牌；气环只画轮廓；目标带三角形；最后一手为双环/圆点；候选点为十字和虚影；区域同时显示纹理形状与文字缩写，均不只依赖颜色。

概念图有一处必须按共享规范纠正：9 路列名应为 `A B C D E F G H J`，不能出现 I。最终实现以 `COLUMNS` 常量为准。概念中的“当前点 E5，黑子，可落”也不符合占点语义；最终示例会显示真实状态，如“黑子，占用，不可落”。这些是规则与可访问性修正，不作为设计偏离。

响应式规则：容器按可用宽度收缩；每个命中区不小于 32px。5/9 路尽量适配窄屏，13/19 路保持最小命中尺寸并在棋盘区域局部滚动。缩放改变实际布局尺寸，不用视觉 transform；复位同时恢复 100% 与滚动原点。投影模式增大文字、棋子与线条对比，不改变数据、坐标或回调。

可访问性：棋盘为带行列计数的 grid，单一 roving tab stop；方向键、Home/End 移动，Enter/Space 调用当前模式唯一回调。原生 click 统一鼠标和触摸，避免 pointer/touch/click 重复绑定。只读和不可落点仍可获得焦点并听取原因，但不触发动作。所有标记进入点位可读描述；动态状态使用一个 polite live region。
