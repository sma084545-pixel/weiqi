# 限制与未测

- 发布正在进行，Render新接口与正式站全链路未验收前不标完成。旧后端会返回需更新；基本本机教学、真人对弈与存档不依赖AI成功。
- 轻松/标准/挑战仅相对搜索预算，不等于确定级位。小模型可能走出低质量着法，有限搜索无法保证最强手、死活或目差准确性；不做段位承诺。
- AI不自动认定任意死子，也不伪造双方身份确认；双停后由使用者与同伴核对。认输不数假分。没有自动AI认输阈值，合法pass可正常结束到人工清单。
- 访客需联网获取新着法。免费服务可能休眠、冷启动或忙；12次AI/IP/分钟、全服务18次/分钟、1计算+2排队，会限制快棋与多人同时使用。无后台保活、无付费扩容。
- 分析请求最多256KB、1600有效事件，极长棋局可先导出。公共本机备份沿用T16单记录5MB/总20MB限制；大棋局快照可能先触及存储空间，页面提示导出。并非无限容量。
- AI续玩JSON包含对手设置；标准GameState JSON/SGF主线用于共同文件交接和复盘。暂未把任意外部SGF直接导入AI对局，SGF不完整承载终局注释/undo/redo，保留续玩JSON。
- 悔棋/历史浏览会暂停AI；恢复页面也暂停，由使用者明确继续。只读历史不能悄悄改写当前棋局。
- 独立画中画依赖浏览器支持；不支持时用可操作的页内悬浮整盘。实际手机Safari、独立PiP新AI模式、长时稳定性、多用户负载及人类棋力校准未测。
- 原37个进阶场景与13路引导课程的本地教学机器人保持原范围，并未冒充本次真实KataGo对手。正式题库、课件、纸卡与其revision均未修订。
