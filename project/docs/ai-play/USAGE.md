# 与 AI 下一盘

从顶部“AI 对弈”，或自由双人对弈页的“与 AI 练习”进入。原网址入口： https://sma084545-pixel.github.io/weiqi/#/play/ai 。

1. 选择5/9/13/19路、你的执色与难度。默认9路、贴目0（教学选择，可和棋），开局前可改半目。自由放置让子由白方先行，不代表正式固定让子。更改尺寸时先确认起始黑子会被清除。
2. 轻松、标准、挑战分别使用8/24/64次最大搜索预算；轻松可在真实搜索过且评价接近的候选中变化，不随机生成棋盘坐标。它们是相对强度，不保证对应初学者水平或任何段级位。
3. 点击交叉点落子。轮到 AI 时不能再替自己下一手；可“暂停 AI 思考”。超时、服务繁忙、休眠或断网会保留局面，由你手动“继续 / 重试 AI 落子”，不会自动无限请求或换成假 AI。
4. “撤回一手”恢复上一项对局操作；“撤回最近回合”最多恢复两手，让你重新选择。重做恢复同一路径；新着法会清除旧重做分支。悔棋后 AI 暂停。滑动条/方向键/Home/End只读回看，回看时也暂停 AI。
5. 悬浮小棋盘、画中画和最大化与主棋盘同步。小窗整盘显示且可按轮次操作；历史局面只读。浏览器不支持独立画中画时自动使用页内小窗。
6. 双方连续停手进入人工终局核对：整块标记死子，先后核对黑白同一清单，再按共同面积规则计分。AI没有替玩家确认任意棋块死亡。修改标记取消之前确认；争议恢复原盘与超级劫历史。你可在轮到自己时认输；认输不编造数子分数。
7. 结束后拖动滑动条，点击“分析当前复盘局面”，才显示真实引擎候选、变化、黑方胜率与预计目差。估计不是最终裁判，不改变已确认结果。

# 保存与恢复

每次合法动作、悔棋和待确认死子清单自动保存在当前浏览器的公共本机存储中，和真人对局分开。刷新/回到本页会恢复并暂停 AI，以免重复请求。手动保存、导出 AI 续玩 JSON、标准棋局 JSON 和 SGF 主线均可用；续玩 JSON 还带难度、执色、完整重做路径和待确认注释。

读取或导入前确认替换当前页面。坏文件必须通过共同规则重放，失败保留原棋局和原存档。SGF 主线可用于交流，不含所有终局操作或 AI 设置；保留续玩 JSON 才能完整恢复。完整备份和清除范围沿用“教师视图 → 离线与本机数据”；清学习进度不清棋局，清棋局会同时清 AI 与真人棋局。已有人工存档键和学习进度结构未改变。

新着法和赛后分析需要联网及可用的 Render 服务；休眠后首次请求可能较久。可以先导出，再稍后重试。没有账号、公开排名、强制计时或自动上传反馈。
