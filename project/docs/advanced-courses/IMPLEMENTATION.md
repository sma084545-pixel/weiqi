## 判题与棋盘

- 复用唯一 Board、T05 StepPlayer、GameTimeline、T10静态集合判题和T01规则。
- 六类交互：文字选择、双棋形比较、直接落点、整块选择、气点集合、顺序落子。序列由使用者按黑白轮次操作，没有尚未实现的异步对手回复。
- 正确/次优/有已核查问题分别给理由。战略判断只针对题干目标与候选比较；未知合法手/路线显示未判断，不算错；非法操作不改状态。
- 落点字母仅是Board新增可选text标记；坐标、交点命中、键盘导航、提子/超级劫/计分算法没有另写。放大只扩展棋盘内部滚动，附复位。
- Guided Example仅显示规则重放的不可变状态；切分支、切课、离开时卸载取消StepPlayer计时器。减少动画可直接到真实终点。
- 提示按观察、关系、关键步骤逐层揭示。答案、气的核对标记与验证字段不会默认渲染。重试清空本次选择、提示与反馈。

## 教学正确性与限制

“有气”不等于已活；“跳/飞”不等于规则上已实连；空三角/直线本身并非无条件坏形。7-04在明确辅助子和外部条件下核查两种切入的连接应对；当前未实连会明说。8-02征子给出完整23手到真实9路盘边；8-03有引子的追征线与两条枷线分别重放。倒扑三手的提子数独立列为0/1/3，最终布局不同，不误认劫禁着。

9-02/03/05/06使用中腹相邻、被外墙限制的目标块，给出无眼/无公气/无外援条件；只断言指定局部任务。3气对3气确实分别设置黑先与白先并核查反向结果。公气用黑独有/白独有/公字与不同环线区分，提交后才核对。9-07沿用LIFE-001 revision1完整布局，核对两个眼的真实禁着，不制作通用死活识别。

10/11课的方向比较不伪称精确全盘最佳手或确定目数。攻击示例允许白做两眼、黑连成外侧，明确局部任务不等于整盘获利。12课只有一个四手原创接触示例，解释靠、扳、连接；不冒称固定定式，不要求背谱。

所有棋形/文字/代码由本项目原创或明确引用既有LIFE内容。独立点集与提子预期由助手逐点推导，自动引擎交叉核查；humanReviewed始终null，不能当作人类教师审查或课堂成效。

## 13路教学机器人

GuidedGame复用T08 FullGameMatch模型、死子确认、争议恢复和ScoreDetails。使用T01真实落子、停手、撤回、完整历史和面积计算；认输不编分数。人执黑，机器人执白；它是简单、确定性的本地规则策略，不是KataGo或人类段位模拟。

白方优先可提棋/自己的打吃，再从角边与适度距离的候选中找合法且非自打吃的一手。每次只执行一手。100手预算后停手，或跟随人的停手进入人工确认；这不是宣告所有棋活。确认由使用者与同伴核查双方，机器人不会自动判断任意死活。

四类观察暂停：开局；实际出现黑方一气块；实际出现合法可提白块；至少12手且当前无打吃时的方向比较。每类一次，可跳过。没有出现某类局面就不伪造战术节点。白方等待、历史浏览、确认重开/认输时不能误走黑方；离开页面/环节取消尚未执行的回应。

## 保存、版本与兼容

主学习记录仍为go-club:learning-progress:v1 / IndexedDB公共StoragePort。只增加可选advancedLessons，按STAGE-id@lessonRevision分隔；新自选标记也在该记录内，旧stageMarks仍只写原六课，旧客户端能继续读取其原字段；场景尝试另带sceneRevision，升级不沿用旧答案。旧六阶段v1记录无需重写即可读取；清学习进度不删除题库、草稿或棋局。

引导棋单独使用go-club:full-game:guided13:v1，包装可重放GameState、待确认死子、确认顺序和已看观察点。一次键写入避免棋局与注释不同步；加载时重放棋局并核对整块注释，坏数据不覆盖。与原LOCAL-T08-FULL-GAME完全隔离。导出仍是共同GameState JSON，T15按原规则读取。全机备份/恢复与选择清除沿用T16，不加新的本地数据库或网络上传。

新增schemas/advanced-course.schema.json是版本1课程补充，引用既有Coord/Position/Move。它不是改写正式content.schema.json；通用题库编辑/导入不会把这些场景冒充T09题，新增课程编辑器、对应纸卡/PPT、更多AI与中级内容可后续扩展。
