已实际查看课程7比较与次优反馈、360公气、360完整底层13路的棋块选择、768键盘作答及1280引导棋截图。路径output/playwright/advanced-*.png。可读坐标、黑白灰度、候选字母、目标三角、选择框与不同气环没有混成同一种标记。未提交时没有标准气环或内部验证字段。

360px的完整13路使用棋盘内局部滚动，可放大点选与复位；页面本身无横向溢出。局部概念优先5/9路。滚动裁口不是规则盘边，题面明确完整盘大小和真实边界。768px实测方向键、Space、Tab、Enter作答；减少动画下征子直接显示正确终点。

首次调试全页截图在页面已滚动时捕获到粘性页头位于图片中段，属于全页截屏合成表现；最终脚本先滚回顶部并取消焦点再截图。没有用截图替代互动功能。

视觉检查另发现引导棋控制按钮选择器误覆盖交点，已限定为button:not(.intersection)。补充浏览器断言交点透明、无边框和无内边距，再重新截图核对木色线盘；该修复没有改变规则算法。
