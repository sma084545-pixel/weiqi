# 联机双人对弈 · 0.20.0

打开网站里的“联机对弈”。一人选择棋盘大小、开局贴目并创建房间，另一人在同一个网站输入8位房间码。可用昵称或留空，无需注册或填写真实姓名。创建者执黑、加入者执白；每个房间恰好两席。

- 棋盘支持5/9/13/19路，默认9路、贴目0。5路明确用于小棋盘练习；这些设置不是官方小棋盘标准。
- 各自只能操作自己的执色。落子、提子、自杀与位置超级劫均由同一规则引擎核查；非法操作不换手。任一方断线时暂缓落子，不判负。
- 棋局滑动条只改变自己看到的位置，不改变房间。收到同伴的新着后回到当前盘面；真正悔棋须申请、黑方确认、白方确认，拒绝则保留棋局。
- 连续两次停手进入终局确认。双方先商量，点击整块标记/取消死子，黑白分别确认后才自动数面积并显示胜负。修改清单取消旧确认；有争议时恢复原盘和重复历史。程序没有通用死活裁判。认输不编造面积分。
- 页面刷新会尝试恢复当前浏览器会话中的座位。关闭会话、清除浏览器数据或丢失凭据可能无法找回原座位；这不是账号登录。不要分享座位凭据，分享给同伴的是网站地址和房间码。
- 返回大厅会保留原座位，可按“恢复上次房间”回来。另开一局请双方回大厅，由一人新建、另一人加入新的房间码；加入别的房间会替换本页保存的上次座位。
- 可保存当前棋局的本机副本或导出共同schema的GameState JSON。副本属于本机，可从文件交换读取，不会改变线上房间，不包含座位凭据。本机完整备份不包含服务器房间或会话凭据。

## 两个人怎样访问

127.0.0.1/localhost仅指当前设备，不能发给另一台电脑作为有效联机地址。房间内分别展示“同伴打开的网址”和“房间码”。同一局域网可由一台电脑启动随包Node服务，让双方打开终端显示的局域网候选地址；是否可达仍受路由器和防火墙影响。只有服务电脑需要Node，其他设备只需浏览器。

跨地点使用需要把同一套服务部署到双方可访问的服务器，使用HTTPS并代理WebSocket。交付包是可运行、可部署版本，没有购买服务或自动发布公网网站。操作方法见DEPLOYMENT.md。

## 隐私和离线

只有主动进入联机页时才连接房间服务，发送可选昵称、房间操作、棋局和连接状态。本机学习进度、教师草稿、反馈和CAS记录不上传。没有公开房间列表、聊天、实名档案、排名或AI对手。

联机需要连到运行中的服务。本机教学工具、正式题库和同屏棋盘仍可按原方法离线准备；“已可离线”不代表房间连接可以断开。局域网普通HTTP的非localhost来源通常不具备Service Worker条件；公网HTTPS或本机localhost才可准备完整离线资源。
