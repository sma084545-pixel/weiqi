# T03界面规格

设计参考为`design-concept.png`，继承T02的纯白、深绿、蜂蜜木色、宋体标题和黑白棋子。参考图仅规定视觉层次，不是学生记录或实施照片；最终文字以本任务真实可用范围为准。

桌面首屏使用简单三项导航、一个投影开关、主标题和木纹棋盘信号。设备记录说明紧接首屏；三个意图入口以一个可用、两个恢复状态呈现。路线采用连续轨道和完整棋形，不使用锁、奖杯、百分比或游戏化进度条。手机改为单列，保留所有入口文字与大触控目标。

颜色以文字、边框、形状共同表达状态；未安装状态同时写明原因和替代动作。焦点沿用全局3px深绿轮廓；按钮和关键链接至少约44px高。投影模式通过字号和边框加粗，不依赖动画。`prefers-reduced-motion`关闭平滑行为；`forced-colors`保留当前项和圆形编号。
