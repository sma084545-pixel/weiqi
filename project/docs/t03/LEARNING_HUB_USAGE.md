# 学习入口使用说明

打开应用后先到“学习入口”。三个意图始终清楚显示：第一次接触围棋、找伙伴玩、尝试一道题。前两个分别进入气实验室与同屏双人吃子小游戏；正式互动题目尚未安装，因此第三项不生成指向未来页面的启动链接，而是提供学习路线和互动棋盘等可用恢复路径。

“学习路线”列出六个可自由打开的阶段。T04气实验室已接入第一阶段，T05提子实验室与T07吃子小游戏已接入第二阶段，T08完整小棋盘对弈已接入第三阶段，T06自由实验棋盘可供任意阶段摆形和规则试下；正式题库仍由后续任务实现。直接打开第五阶段不需要完成前四阶段。各阶段只显示短目标、动手建议、观察点、分流说明、完整棋盘示例和当前可用范围。

访问阶段简介或互动棋盘练习后，首页出现“继续上次”。“我会了”和“还想练习”是本人留给自己的可改标记；没有积分、百分比、连续记录、排名或访问限制。“清除本机进度”需要二次点击，只删除T03专用记录，不删除随项目提供的题目或其他内容键。

顶部“投影模式”和教师视图中的同名开关同步，放大主要标题、操作与状态文字。教师视图可打开当前可用活动，并按需展开以完整9路为主的5+8+25+5+2分钟建议；它不是学校已经采用的安排。

手机上顶部导航分为品牌/投影行和三项导航行。所有入口和按钮保持可触摸尺寸，页面不横向滚动；棋盘自身的局部滚动继续由T02 Board负责。键盘可Tab遍历导航、入口、阶段及进度操作，焦点样式可见。

本应用无账号，不会默认把进度上传到网络。T03只定义当前浏览器设备的公共存储行为；离线资源、备份和迁移由T16扩展。
