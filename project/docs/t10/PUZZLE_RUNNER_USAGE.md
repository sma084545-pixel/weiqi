# 互动挑战题使用说明

从首页“我想尝试一道题”、学习路线第 4–6 阶段或教师视图进入 `#/challenges`。旧地址 `#/challenge/try-one` 继续作为兼容入口。目录按六类别和“入门 / 进阶 / 自选挑战”文字难度筛选；这些标签帮助选题，不判断棋力，也不限制打开后续题目。

题目页显示正式 ID、revision、目标、先手、完整棋盘边界和必要教学条件。题目答案、验证内部字段、作者证据与解题代码在提交前不渲染。三层提示分别为“观察什么、考虑关系、展示关键步骤”，每层单独打开；“隐藏提示并重试”会收起提示并清空临时回答。

六种作答方式：

- 数字：输入 0 或更大的整数。
- 空点集合：点击空点，再次点击取消；键盘可用方向键移动并按 Enter/Space 选择。
- 落子变化：点击合法空点；播放器只对题库覆盖分支作断言，必要时播放题目写明的对方回应。
- 区域归属：先选黑方、白方、中立或未知，再点空点；再次用同一标签点击会取消。
- 理由选择：可选一项或多项，按题目模型比较完整集合。
- 开放文字：记录选择、依据和对方回应，进入讨论状态，不自动判唯一答案。

“自由试下”从原题局面或当前未知合法手继续使用 T01 规则引擎，明确离开判题状态。返回后恢复原题，不把试下着法写入题目回答。切题、重置、回到列表或离开路由会取消尚未播放的题目回应。

本设备只保存 `schemaVersion + id + revision` 对应的尝试次数、已打开提示层级、最后状态和是否完成。没有账号或默认网络上传。题目 revision 改变后，旧 revision 的完成标记不会套用到新题。
