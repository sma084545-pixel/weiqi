# 棋局回退与滑动条 · 0.19.0

每个可按规则连续落子的棋盘下方都有“棋局滑动条”。拖动立即显示对应局面；“回退到上一步”“前进一步”“回到开局”“返回当前局面继续”可精确切换。键盘先 Tab 聚焦滑动条，左右方向键逐步移动，Home 到开局、End 到当前。没有额外播放动画或音效。

## 哪些界面可用

| 界面 | 入口 | 实际撤回方式 |
|---|---|---|
| 自由双人对弈 | 首页“双人对弈”，`#/play/free` | 返回当前局面，申请悔棋，由双方先后确认 |
| 完整小棋盘对弈 | `#/play/full-game` | 同上；两入口仍共享同一份保存 |
| 双人吃子小游戏 | `#/play/partner` | 同上；结束后也可撤回获胜一手 |
| 自由实验棋盘的按规则试下 | `#/board/experiment` | 返回当前局面，“撤回对局”或“重做对局” |
| 挑战题中的落子变化 | `#/challenges`，选落子题 | 返回当前局面，“回退一步”；恢复对应答案节点与反馈 |
| 挑战题内的自由试下 | 同一题的“自由试下” | 返回当前局面，“回退一步”；不改原题和成绩 |
| 教师答案变化编写 | `#/teacher/editor`，变化树题型 | 滑动在当前路径选择节点；在旧节点新增着法会保留原分支 |
| 组件验证中的落子棋盘 | `#/board-lab` | 可回看和返回当前；它仍是开发验证示例 |

气环、区域标记、静态教学题不是轮流对弈，没有虚构落子历史。提子实验室保留原有“上一步/下一步”的中间演示帧操作，动画帧不会混入真实棋局。

## 回看与悔棋

滑动条是只读回看：不改轮次、提子数、劫史或保存，也不会替玩家撤销某一手。回看旧局面时禁止继续落子、停手或确认终局；先返回当前。真正撤回仍由规则引擎恢复完整状态；双人对弈保留双方确认的现场约定。

范围包括开局设置和当前有效路径中的每项操作：落子、停手、认输、争议恢复、最终计分确认。它不包含撤回后尚未重做的支线，也不能重建摆棋起点之前未知的历史。真正撤回/重做、换题、读入另一局或重开后，范围立即跟随新状态，光标回到当前。查看旧局面时不会把当前终局分数或被提标记套到旧盘面上。

吃子小游戏可回看整局，结束时仍提供最后最多五手的快捷播放。正在播放题目预设回应时暂时锁定滑动条与进入自由试下；回应完成后可回看。切题或重置会取消旧回应。

刷新会恢复软件原本可保存的当前对局，回看光标不另存；吃子小游戏、临时试下等仍遵守原模块的保存范围。保存的是最新真实局面，不是临时滑到的旧画面。

## 更新与离线

完整工具包版本 `0.19.0-history.1`，程序版本 `0.19.0`，从 `0.18.0-freeplay.1` 延续。现有数据库、schema、规则、正式题 revision 与材料不变，无数据迁移。先在旧软件导出本机备份，再在相同主机与端口更新并重新完成离线准备；保存当前工作后应用更新。更换端口属于另一存储来源，不会自动显示旧端口的本机记录。

可使用生产构建本地服务（需要 Python3）：

    python3 -m http.server 4190 --bind 127.0.0.1 --directory dist

打开 `http://127.0.0.1:4190/#/play/free`；不要直接双击 HTML 代替服务。完整开发、构建与测试命令见根 README。
