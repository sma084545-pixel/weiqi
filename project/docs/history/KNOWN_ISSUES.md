# 限制与恢复

- 滑动条回看不改真实对局；不能在旧局面静默覆盖后续。真正悔棋需回到当前，按原模块按钮操作；双人对弈继续使用双方确认。
- 范围是当前有效事件路径，包含停手、认输和管理操作；不含未重做支线和未知的摆棋前历史。教师答案树通过节点列表切换分支。
- 题目预设回应的约半秒期间暂不能拖动或进入自由试下；可退回/重置/离开以取消。不是加载完整题目答案给学习者。
- 回看光标不保存，刷新回当前；吃子小游戏与临时试下的跨刷新保存范围未扩展，保持原模块边界。
- 实际浏览器为自动化Chromium151.0.7922.34及WebKit26.5；不是原生Safari、手机/平板实机或真人辅助技术。Firefox、Edge、VoiceOver等本次未测。WebKit禁网自动化已知工具限制仍在，Chromium实际禁网刷新已测。
- 直接file://不支持完整离线安装；需要本地服务或HTTPS。旧页更新先保存/备份，再应用新版本，重新检查离线准备。更换端口不共享原存储。
- 任意棋块死活仍需双方确认；此功能未添加自动死活、棋力评估或新赛规。原T24实体材料的实际打印/制造/课堂验证继续未测，详见docs/t24/known-issues.md。
