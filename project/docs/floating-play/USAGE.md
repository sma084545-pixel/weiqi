# 悬浮小棋盘直接操作

原网站：https://sma084545-pixel.github.io/weiqi/#/play/online 。前端0.21.2。

1. 创建或加入房间，在棋盘上方点“悬浮小棋盘”。轮到自己的执色时，直接点击小窗内的空交叉点落子；主棋盘与同伴同步。
2. 只拖动顶部“拖动小棋盘”按钮来移动小窗；也可以聚焦该按钮后按方向键。棋盘内的点击用于落子，大棋盘的滑动用于局部滚动。
3. 5/9/13/19路都显示完整真实棋盘。交叉点保留至少约32px点击区域；13/19路可在小窗内横向和纵向滚动。“复位小窗”将小窗位置和棋盘滚动都复位，“放大棋盘”打开大窗。
4. 键盘在棋盘内用方向键移动焦点、Enter/Space落子；焦点移到小窗外的棋盘部分时局部滚动跟随。
5. 浏览历史时所有棋盘只读。用棋局滑动条返回当前手，才可继续；真正悔棋仍须双方确认。等待同伴、断线、提交中、悔棋确认中和已结束时均不能额外落子。
6. 双停后的终局确认中，小窗也可点击整块标记/取消死子；这只是待双方确认的注释，不移除历史中的棋子。双方确认仍在主页面完成。
