# 自由双人对弈 · 0.18.0

首页“我想找个伙伴玩 → 开始对弈”，或顶部导航“双人对弈”，即可进入。直接地址为已启动应用的 `#/play/free`。这是两人在同一屏幕轮流操作的完整围棋；没有电脑对手或联网匹配。

1. 开局前选择5、9、13、19路，默认9路。5路显著标为小棋盘练习。可设置白方贴目，默认0、允许和棋；开局后锁定尺寸和贴目。
2. 点空的交叉点落子，黑先、白后；如使用自由放置让子，验证后白先。当前执色有文字与黑白棋子提示。提子、自杀禁着和位置超级劫由统一引擎处理；非法动作不换手，也不增加历史。首次提子不会结束完整围棋。
3. 认为已下完时，双方各按一次“停一手”。核对死子时点任一棋子可标记/取消整块；若盘上均活，可直接依次按黑方、白方确认。程序自动计算活子、围空、贴目和差值，并在顶部显示黑方获胜、白方获胜或和棋。
4. 自动算分需要双方确认死子与中立点，程序不猜任意棋块的生死。若有争议，提出争议并恢复对弈，保持原盘及重复历史。认输确认后立即显示对方获胜，不编造面积分。
5. 双方同意可悔棋，也可保存、导出JSON或逐项复盘。刷新自动恢复当前设备保存的完整对局。旧入口`#/play/full-game`保留，与新入口使用同一盘完整对局和存储键。

键盘：Tab进入棋盘，方向键移动，Enter/Space落子。手机大棋盘可在棋盘区域局部滚动，使用原有缩放/复位控件；不会把整个页面挤出视窗。无倒计时、公开排名、账号或默认上传。

离线：先按“教师视图 → 离线与本机数据”准备至“已可离线”，之后断网刷新仍可下棋。PDF/PPT材料仍需单独保存在本机。直接双击file://不提供同等离线能力。
