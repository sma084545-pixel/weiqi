# T04 界面规格

桌面采用演示选择、三种模式和“棋盘 / 任务”双栏；980px 以下改为棋盘在上，650px 以下模式卡单列。演示选择横向滚动，按钮最小高 48px。视觉沿用 T03 白底、森林绿与木色棋盘，没有远程字体或装饰图片依赖。

信息揭示顺序是设计约束：预测前只呈现中性标题、棋形、选中棋块轮廓和操作说明；提交有效答案后才加入气环、数量、坐标与教师说明。`hidden` 不用于在 DOM 中预埋答案；相关节点在 `revealed` 为真时才创建，避免视觉、查找、辅助标签或旁侧文本泄题。

标记从底到顶保持区域、候选、棋子、气环、整块双线、目标、最后一手、数字、不可用、单点选择与焦点。双线轮廓不覆盖棋子“黑/白”字；虚线气环、加号候选和轮廓在灰度下仍凭形状区分。

`docs/t04/design-concept.png` 是 ImageGen 的桌面/手机方向稿，不是实现截图、教学棋形依据或使用成效。真实截图以 `output/playwright/t04` 为准。
