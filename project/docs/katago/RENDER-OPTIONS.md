## Free 与额外费用

- 15 分钟无入站流量后，Free Web Service 会休眠。新的 HTTP 请求或 WebSocket 连接会触发唤醒，平台说明约需一分钟；KataGo 加载模型的时间另计且尚未实测。不得使用持续自我请求规避休眠。
- 每个工作区每月共用 750 个 Free 实例小时，**不是每个服务各有 750 小时**。已有联机房间服务与新的分析服务若同属一个工作区，会共享该额度；账户归属和实际用量尚未核实。超额可能暂停 Free 服务。
- Free 只有单实例，不能附加持久磁盘；无 Shell/SSH 和一次性任务。运行时文件在重启、重新部署或休眠后不能保证保留，不能依靠运行时下载留下模型。
- 当前 Hobby 工作区公开月费为 $0，计算资源另外计价；包含 5 GB/月出站流量，超额 $0.15/GB；标准构建包含 500 分钟/月，超额 $5/1000 分钟。付费计算资源并不要求另外购买 Pro 工作区。
- 有付款方式时，带宽或构建用量超额可能产生费用；无付款方式或达到相应限额时可能暂停服务/构建。尚未核查账户的消费限制，不能承诺新增 Free 服务的整月总账单必为零。不要增加数据库、Redis、磁盘、监控订阅或自动扩容。

来源：[Free 限制](https://render.com/docs/free)、[当前定价](https://render.com/pricing)。

## 可重建部署配置的要求

1. 使用 Docker **Web Service**；Static Site 无法运行常驻 KataGo 子进程。HTTP 监听 `0.0.0.0`，读取 Render 的 `PORT`（平台默认 10000）。新服务使用 Render 分配的 HTTPS 地址，前端仍保留原 GitHub Pages 地址。
2. 单实例、单 API 进程、一个常驻 Eigen CPU 引擎。普通实例不能假定有 GPU。引擎、依赖和模型固定版本，在构建阶段下载并校验，避免每请求重新启动或下载；模型权重不进入普通 Git 历史。
3. Render Docker 构建使用 BuildKit，支持多阶段构建、层缓存和 `.dockerignore`。镜像内置模型以适应临时文件系统；不要把秘密作为 Docker `ARG`/`ENV` 写入镜像。
4. 提供轻量进程状态接口和独立就绪状态。就绪检查不执行搜索；模型未加载或引擎失效时不能假报就绪。Render HTTP 健康检查要求 5 秒内返回 2xx/3xx；新部署最多等待 15 分钟全部健康。运行实例连续失败 15 秒后暂停路由，60 秒后重启。
5. 官方允许 Web Service HTTP 响应最长约 100 分钟、构建最长 120 分钟；这不是本项目分析截止时间。项目仍须限制单次搜索、短超时、有界排队和取消，避免昂贵请求长期占用实例。
6. 仅允许实际正式 Origin `https://sma084545-pixel.github.io`；Origin 不包含 `/weiqi/`。CORS 不是身份认证，不能替代输入、频率和计算资源限制。

来源：[Web Services](https://render.com/docs/web-services)、[Docker](https://render.com/docs/docker)、[Health Checks](https://render.com/docs/health-checks)、[请求与构建时限](https://render.com/docs/render-vs-vercel-comparison)。

## 模型与实例选择尚待实测

当前准备中的模型候选为官方 general `g170-b6c96` 小网络（约 3.65 MiB 下载体积）。下载体积不等于加载后的内存占用。引擎代理仍在核查版本、校验值和实际运行，**本文件不把它当作已验证可运行配置**。

只有真实引擎加载后，才可记录启动时间、代表性局面耗时、峰值内存和少量并发排队。Mac 本机结果不能直接当作 Render Free 的性能证明。若 512 MB 内存足够且实际等待可接受，可先验证 Free；若不足，不应先创建同为 512 MB 的 $7 计划来“修复”内存问题。需要付费时先提供实测、计划规格、持续费用和限制，等待用户确认后再创建。

## 实际访问边界与下一步

主任务报告：Render 后台的浏览器访问已两次被已保存的权限策略拒绝；即使用户口头表示已允许，当前工具仍返回权限拒绝。因此不能用 CLI、API 或其他通道绕过这一拒绝。本文件没有进行账户操作，也没有读取或请求秘密。官方 CLI/API 的存在不构成访问授权。

独立的代码、部署配置和不依赖付费资源的测试可继续完成。真正创建或部署服务时，需要用户在 Render 后台完成当前被阻止的最终操作；应先提供已准备好的准确配置。预算未授权时不得选择付费计划。
