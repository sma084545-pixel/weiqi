# 自由实验棋盘使用说明

稳定地址是 `#/board/experiment`。页面有两个明确状态：“摆棋示意”允许任意放黑、放白、擦除和标记，不自动轮换或提子；“按规则试下”只在当前局面通过 `validateSetup` 后建立一局新的 GO-CLUB-AREA-1 试下。页面始终说明摆棋不是棋谱，也不声称知道起点以前的劫史。

## 摆棋示意

- “放黑”“放白”会直接覆盖交点颜色，不触发提子；“擦除”同时清除该点的棋子和标记。
- “选择棋块”只查看同色上下左右相连的整块。先关闭“显示气”可让成员猜测，再打开核对。
- “目标标记”切换三角；“数字标记”写入 1–99。工具均有文字状态，手机不需要右键。
- 撤回/重做只作用于摆棋编辑；新编辑会清除旧重做分支。清空需要二次确认。
- 改变完整棋盘尺寸前，页面列出会被裁切的棋子和标记数量。确认后按左上 `row,col` 重叠范围保留；该尺寸变化仍可撤回。

无气棋块会保留并以目标形状和文字指出。这类教学示意不能进入规则试下；擦除或改摆使全部棋块有气后即可继续。

## 按规则试下

进入前选择下一手、贴目（Komi）和完整围棋/首提练习，并勾选“从这里建立位置超级劫历史”。确认表示：当前布局是唯一已知起点，过去未知。建立后的 `history.layouts` 只有当前完整布局一项。

规则模式复用 T01 的 `tryMove`、`applyPass`、`undo`、`redo` 和 `resumePlay`。同色不能连续下；非法着显示稳定中文原因且不改变盘面。两次停手在完整对弈进入终局确认，但本页不自动判断死子或显示面积胜负。首提模式贴目固定为 0，并由 T01 决定首提结束。

“撤回对局/重做对局”恢复规则引擎的完整快照，与摆棋撤回完全分离。选择“把当前盘面带回摆棋示意”会把最终盘面写成一次可撤回编辑；此后旧的轮次、提子、停手和落子序列不再被声称对编辑后的盘面完整有效。

## 保存和导出

“保存当前设备”使用公共 `browserContentStore`，没有账号或默认网络上传。保存内容可以清除或被浏览器存储策略移除，不能当长期备份。

“导出 Position JSON”生成 schemaVersion=1、`historyPolicy=fresh-setup`、`history=null` 的共同 Position，只含盘面与下一手；现有封闭 Position 模型没有标记字段。“导出 Position 与标记”生成 ContentBundle，第一项为同一 Position，其后每个目标/数字标记是独立 MarkerDocument，因此可以由共同校验器完整回读。通用文件导入与 SGF 属于 T15，本页只读取自己保存在设备上的这一份临时实验包。

键盘用方向键移动焦点，Enter/Space 应用当前工具。触屏只需轻触。投影模式放大界面；减少动画由系统设置控制。Safari、Firefox、实体设备和专用读屏器仍需后续实测。
