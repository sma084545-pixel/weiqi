# 眼与基础死活小课使用说明

入口为 `#/learn/life`，也可从学习路线第 5 阶段进入。短课可以随时跳过；页面首尾都提供返回完整对弈的链接。

1. 在“能否落子”中先选预测，再选棋盘上的候选点并验证。假眼示例调用 T01 规则引擎得到白 C3 合法且提三子；两个独立真眼示例由同一引擎拒绝白 B4 自杀。错误选点只提示重新选择，不改变局面。
2. 比较 `LIFE-001` 的两个独立单点眼与 `LIFE-005` 的两个相连空点。两个空点的数量相同，结构不同。
3. 用四帧演示逐步填外气。帧只改变演示 Position，不写入对局历史；最后才让 C3 成为三个目标块的共同最后一气。
4. “黑先/白先”对照从同一 `LIFE-003` 布局分别建立 `fresh-setup`，同步改变 `toPlay` 并各自重放 B5。白先合法只说明关键点被占，不自动宣布黑块死亡。
5. 点击 LIFE-001–005 后进入已有 T10 播放器。提示、变化树、反驳、未知分支和本机进度仍由 T10 处理；返回后原短课可继续。

页面中的“活”“死”只引用题目写明的局面、轮次、目标与变化证据。`LIFE-005` 的 `verified-dead` 只适用于其完整 5×5 和已覆盖的有限变化；没有两眼不自动等于死亡，双活等情况存在。
