# 安全与限制

- 导入内容始终按不可信文本处理；不使用 `dangerouslySetInnerHTML`，不执行脚本、HTML、事件属性或外链。
- JSON 在业务校验前检查字节数、文档数和嵌套深度。SGF 检查字节数、节点数、游戏数、括号/属性语法与支持范围。
- 文件名去除路径分隔、控制字符和不安全符号；下载名只由稳定 ID、revision 与固定后缀组成。
- 未知 schema 主版本、非 UTF-8 SGF 声明、坏 setup、非法轮次/着法、非根 setup、规则冲突未确认均失败关闭。
- 失败预览和失败提交不覆盖已保存内容；错误包含 JSON 字段路径或 SGF 节点路径。
- 本机保存键为 `go-club:file-exchange:v1`。未知未来版本拒绝读取，不自动降级或擦除原字符串。
- T15 不上传第三方，不解析 HTML，不运行宏，不承诺全部 SGF 扩展兼容。

默认上限：JSON/SGF 各 2 MB、100 个 JSON 文档、32 层 JSON、5,000 个 SGF 节点、10 个 SGF 游戏。界面只允许在安全范围内调低或调节；测试覆盖超限拒绝。
