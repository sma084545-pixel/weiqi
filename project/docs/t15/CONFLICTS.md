# T15 冲突与解决记录

1. **GameRecord 名称与既有 schema**：任务用“GameRecord”，共同 schema 只有 `GameState`。解决：界面使用 GameRecord 作为易懂名称，保存仍用 `kind: "GameState"`，不新增平行 schema。
2. **SGF 与 GO-CLUB-AREA-1**：SGF 的 `RU` 可指向其他赛规，也可能缺失。解决：保存前显示 conflict/unknown 并要求明确同意只在本项目规则下试导入；不改 rulesetId。
3. **SGF 树与线性对局**：T08 GameState 是明确动作路径，SGF 可多分支。解决：完整原树单独保存，线性功能必须选择根到叶路线，并显示未加载分支数。
4. **非根 setup/PL**：首版不能把中途摆子重建为合法对局历史。解决：保留输入原文并阻断导入，报告具体节点；不静默忽略。
5. **教学元数据与 SGF 表达能力**：提示、验证、量规、终局确认无法标准无损表达。解决：JSON 定为权威格式，SGF 导出返回字段损失警告。
6. **外部题与正式题 ID**：外部内容可能与正式 30 题/END 重名。解决：禁止直接 replace，只能跳过或生成 COPY ID；导入题进入未发布 T14 草稿。
7. **PDF 坐标初次目检不可见**：文字填色继承背景色。解决：在坐标文字前显式设置深色填充，增加 PDF 命令测试并重新渲染逐页检查。

没有共享规则、schema、坐标、正式题 revision 或依赖冲突需要迁移。
