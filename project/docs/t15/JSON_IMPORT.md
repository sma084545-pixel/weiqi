# JSON 导入与冲突处理

入口：教师视图 →“文件交接与棋盘图”，路由 `#/teacher/file-exchange`。

1. 选择文件或粘贴文本后先点“安全预览”。此时不写本机内容。
2. 预览列出文档类型、数量、字段/题目定位错误和 ID/revision 冲突。
3. 冲突必须逐项选择：跳过、显式替换，或以新 ID 保留副本。正式 30 题和 END-001–006 不能被普通导入静默覆盖。
4. 只有全部选择有效后才提交。Puzzle 会作为未发布 T14 草稿交接，外部 `validation` 不会直接取得“已发布”资格。

默认限制为 2 MB、100 个文档、JSON 嵌套 32 层；界面可在更小范围内调整。超限、未知主版本、坏 JSON、重复占点、非法历史或题树着法会在提交前失败，已有内容保持不变。文件名经过规范化；所有文本由 React 作为文本节点显示，不执行 HTML、脚本或外链。

`ContentBundle` 会展开为独立文档参与预览和冲突处理。完整题目往返保留 ID、revision、棋形、轮次、提示和变化树。`GameState` 不信任外部缓存的提子、赢家或历史，而是从 setup 与动作重放恢复。
