# 固定预期与独立手算

`DEV-END-T08-001` 是开发验证终局，不属于正式题库，不声称来自实战或经人类教师审核。9路盘除三个空点外填满：逐行列数得到黑子35、白子43。

- (1,1) 四个正交边界全是黑棋，所以是1点黑空。
- (7,7) 四个正交边界全是白棋，所以是1点白空。
- (4,4) 同时接触左侧黑棋与其他方向白棋，所以是1个中立点。
- 黑方面积=35+1=36；白方面积=43+1+贴目0=44；黑减白=-8，白方领先8目。
- fixture另列黑提9、白提2，仅验证它们不进入面积公式。

这组数字先写入 `tests/fixtures/t08-full-game-expected.json`，再由测试调用 `scoreArea` 比对。局面石块均至少有气，Position通过schema和setup验证。固定案例通过不等于证明任意终局死活。

完整交互流程另用空盘实际走B(0,0)、W(8,8)、双方停手。未标死子时两子之间79个空点同时接触黑白，面积1:1为和棋；把整块B标死后，原棋盘不变，计分副本只剩1颗白活子与80点白空，最终白81、黑0。
