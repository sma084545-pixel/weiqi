# 完整小棋盘对弈使用说明

从学习路线第三阶段或 `#/play/full-game` 打开。设置页与对弈页分开：先选9、13或19路，开局前设白方贴目；默认9路、贴目0并允许和棋，这是本项目教学选择。

“空盘”由黑方先行。“本社团自由放置让子”允许在完整棋盘任意点击放置或移除起始黑子，至少一颗，确认后白方先行；这不是正式固定让子规则。切换尺寸或改回空盘若会丢掉让子，必须在对话框确认。开始按钮先调用 `validateSetup`，以 `fresh-setup` 建立唯一新历史；未知的更早劫史不会被伪造。

对弈中点击空交叉点落子，所有规则动作由T01处理。停一手不改盘也不清历史；连续两停进入“终局确认”，还未结束。认输立即结束，只记录胜方，不产生面积数值。双方悔棋按黑、白依次在同一设备确认；这是现场操作约定，不是账户身份认证。

终局确认时点击任一棋子会标记或取消其整个正交连通块。任何标记变化都清除旧确认。黑方先接受当前死子与中立点清单，白方再接受同一份清单，之后才显示最终面积结果。预览不改变原棋盘，不以空区染色暗示自动死活裁判；有争议时由提出方恢复原盘实际演示，连续停手归零而位置历史保留。

复盘用“上一项/下一项”浏览规则引擎保存的只读快照。复盘时棋盘锁定；必须按“返回当前局面继续”才可落子。保存到当前设备与JSON导出均保留完整 `GameState`；读取先从setup逐项重放核查。

本页不含自动死活、胜率、官方让子换算、计时器、网络对局或排名。正式教学终局稍后与T09内容对齐；当前开发终局明确标为开发验证数据。
