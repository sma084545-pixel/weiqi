# 辅助下棋使用说明

从“学习路线”课程6之后，或首页“和 AI 边下边学”进入辅助下棋。

建议第一盘：9路、黑棋、适度指导、自动选择、本地教学机器人。它适合练习气、提子与连接，棋力有限；如果希望和真实KataGo下棋，可在开局前选择它，新着法需要联网。

1. 先读当前问题，自己想一个目标。
2. 困难时点击Hint，先看方向；再点击才给区域、候选。只有明确再请求，才显示“试”点。
3. 你自己落子。关键处会解释实际变化，普通着不强行打分。
4. 看完关键反馈，选择继续、回看思路，或悔棋。对手的打吃和提子也会有简短说明。
5. 随时可展开“棋谱回看”，拖动滑动条；回看只读，对手会暂停。真正换一手用撤回操作。
6. 双方停手后，与同伴核对死子与中立点，再依次确认；不确定就恢复原盘面继续。也可在自己的回合选择认输并回顾。
7. 先看本局学习报告，再看结果。选择关键快照重新尝试时，原局会保留；也可回到原局报告。

本机记录与普通对弈存档分开。刷新后对手暂停，不会偷偷落子。保存和导出在“保存、导出与续玩”里；报告可导出Markdown，完整续玩可导出JSON，棋谱可导出SGF。完整备份与选择性清除沿用教师视图中的“离线与本机数据”；只清进度不会删掉棋局、归档或草稿。

提示不是全盘最佳着证明。报告里的次数描述实际棋形和操作，不表示能力等级，也不证明当时已独立发现。基础死活主题不会自动判任意棋块生死。

本地机器人与提示不上传数据。明确选择KataGo时，会将本局起点、着法与贴目发给既有围棋服务取得对手落子，不发送教学记录。服务器繁忙、休眠或失败时，棋局保留，可以手动重试、悔棋或导出；不会自动改用其他对手。

离线使用前，请在教师视图完成离线准备并实际断网试一次。直接双击`file://`不是同等离线环境。正式网站继续使用原GitHub Pages地址；使用已有“新版本已准备好”按钮即可保存后更新，不要通过清除站点数据更新。
