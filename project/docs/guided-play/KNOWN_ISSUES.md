# 已知限制

- 教学建议依据局部规则与有限候选，不是全盘最佳着、战略价值或通用死活判断。复杂切断、真假眼自动识别和KataGo深度教学分析尚未实现。
- 本地教学机器人棋力有限，不与人类段级位对应。选择KataGo时受现有免费服务的休眠、冷启动、限流与队列限制；无自动无限重试或隐藏降级。
- 每盘最多保留最近500条提示请求；当前续玩记录上限5 MB；学习汇总保留最近50个已结束会话。归档随本机棋局备份保留，清除棋局范围会删除这些归档。
- 教学报告记录操作与棋形，无法推断用户是否独立观察、是否掌握概念或是否真实参与教学。没有真人课堂或人类围棋教师正确性审核。
- 终局仍需人核对死子。争议须通过原盘面继续演示；不会拿局部提示或AI评估自动代替终局确认。
- 本次真实浏览器验证范围与设备记录见验收表；桌面触屏模拟不等于实体手机，未运行的Safari/Firefox、屏幕阅读器与长期多人负载不标为通过。
- 没有新增付费服务、数据库、账号、上传学习记录、排名、成就强制通关或长期能力诊断。
