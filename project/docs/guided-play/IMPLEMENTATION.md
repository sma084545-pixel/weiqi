# 辅助下棋 / Guided Play · 0.26.2

基线：最新已交付 EXTREME_AI 0.25.2-pages.1。规则仍为 GO-CLUB-AREA-1，内容与存储 schemaVersion 仍为1。本次是独立模式的增量，不改课程编号、正式题库或棋盘规则。

## 产品路径

学习路线课程6之后的“从知识到实战”入口，或首页“和 AI 边下边学” → 三句话首次说明 → 9/13路、黑/白/随机、指导强度、学习主题、对手 → 自己观察并落子 → 关键着反馈 → 对手回应 → 双停人工确认或认输 → 本局学习报告。

路由 `#/play/guided` 和模块 `guided-play` 使用现有模块注册表。可直接进入，不要求课程通关。普通 AI、真人、联机与课程12原有的13路引导实战继续保留。

设置只在开局前修改。默认9路、黑先、贴目0、Level2适度指导、自动主题、本地教学机器人。自动主题固定选择“气、打吃、连接”三个重点，并非隐性棋力诊断。其余主题每局同样不超过三个重点。

## 数据流与职责

`GameState → PositionAnalyzer → TeachingAnalysis → HintController / overlays / feedback → Board`。

- `core/rules` 是唯一规则计算；`Board` 是原有受控渲染组件，均未修改。
- `analyzer.ts` 调用共享的 `getGroup/getLiberties/tryMove`，核对前后盘面，生成局部问题和解释。候选最多尝试48个点，最多显示3个；每个实际显示候选均通过当前完整历史的合法性校验。
- `PositionAnalyzer` 是异步供应接口；当前 `localPositionAnalyzer` 只在本机计算。未来可由经过局部事实校验的远程适配器替换，不需要让页面知道某一引擎的原始输出。
- `useTeachingAnalysis` 以不可变状态、主题和供应器缓存；取消、换手、换局和失效结果均受到身份检查。
- `useGuidedPlay` 统一用户思考、提示、反馈、对手、只读回看、确认和总结状态。快速连点有同步闸门；真正落子只走已有引擎。
- `useGuidedOpponent` 的本地对手按提子、救一气棋、直接连接与角边发展选择合法候选。可明确选择现有 KataGo；复用原有请求限流、取消、过期结果检查，Level1/2/3分别使用既有轻松/标准/挑战搜索档。本地或远程失败均不悄悄换对手。
- `model/storage` 复用 `FullGameMatch` 和公共持久化接口。独立存档不会覆盖普通 AI、真人或课程12的存档。
- 提示、设置、反馈、叠加标记和总结分别由独立文件管理，页面只组装。

## 分级提示与教学边界

1. 思考方向：一个问题，不显示具体点或棋盘候选标签。
2. 区域：一片淡色点组成的小区域，不表示其中某点一定最佳。
3. 候选：A/B/C，均为已验证的合法候选；没有每点评分。
4. 明确点击“我还需要帮助”后，才显示一个“试”点及因果说明。普通Hint按钮到第三级就停下，连续点击不会直接泄露最终建议。

所有未展开的答案都不进入棋盘可访问标签。清除、换手、悔棋、历史浏览和新分支都会清掉原来的叠加标记。标记通过已有 `BoardMarker` 渲染，不接管指针事件，不修改棋盘。

反馈核对实际提子数、同色块合并、一气棋增气和新打吃。普通合法着不评好坏、不阻塞对手。明显的一气危险会提出问题；不把有意弃子武断判错。Level1可在非提子的自打吃着前先问一次，保留“我还是要下这里”。Level3主要保留一气危险，正面局部变化留到总结。

“好”只描述具体可核实的局部变化，不是引擎证明的整盘最佳手。没有通用切断价值评估、真假眼识别或死活裁判。基础死活主题提供有边界的观察问题；两个空点不等于两个独立真眼，没有两眼也不一概判死。

KataGo目前只作为可选真实对手。即时教学仍是本地规则分析，没有把低搜索预算包装成人类段位，也没有调用LLM解释层、实时胜率、目差、热力图或未经验证的战略判断。

## 对局、恢复和报告

用户关键着后可继续、只读观察上一手之前，或真正悔棋重试。只读观察不覆写对局。历史滑动条在“棋谱回看”中；浏览会暂停对手。撤回、重做与新分支沿用原有完整历史逻辑。

两停进入人工终局确认；修改死子取消之前确认，有争议恢复原棋盘与重复历史。面积得分仅在确认流程中展示；认输不伪造分数。机器人不替人确认棋块死活。

报告只描述实际记录到的操作与棋形变化，不声称学员已经独立发现、掌握概念或真实合作。最多展示3个关键快照、一个改进方向和真实存在的后续学习入口。重试先归档原局，再保留其实际合法历史创建新变化；可保留变化并回到原局报告。

保存键：

|记录|键/命名空间|范围|
|---|---|---|
|当前辅助棋局|`go-club:full-game:guided-play:v1` / games|完整可重放棋局、设置、待确认清单、提示请求|
|归档与变化|`go-club:full-game:guided-archive:<sessionId>` / games|原局保留，可随完整备份恢复|
|辅助学习记录|`go-club:learning-progress:guided-play:v1` / progress|最近50个已结束会话，按稳定id幂等更新|
|首次说明|`go-club:settings:guided-play:intro:v1` / settings|仅首次说明是否已看过|

每盘最多保留最近500条提示请求，续玩文件最多5 MB，与现有完整备份的单条上限一致；长棋局可导出SGF主线。`schemas/guided-session.schema.json` 是附加文档schema；导入仍须规则重放和整块死子校验，不能只信JSON字段。

刷新后对手总是暂停；本地提示与机器人可在完成离线准备后使用。KataGo新着法需要网络，使用原有服务，不新增资源、订阅或费用。
