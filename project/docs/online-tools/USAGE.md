# 联机棋盘窗口与聊天

原网址：https://sma084545-pixel.github.io/weiqi/#/play/online 。程序0.21.0；先创建或加入房间，棋盘上方出现三个窗口按钮。

- **最大化棋盘**：在本页打开大棋盘，仍可落子、停手、回看及聊天。桌面支持时可再点“进入系统全屏”。“返回普通棋盘”或Esc退出；不离开房间。小屏19路保留棋盘内滚动，不缩成难以命中的落点。
- **悬浮小棋盘**：页内可拖动的只读缩略图，跟随当前回看位置。拖动标题；键盘聚焦“移动悬浮棋盘”后用方向键移动。“复位位置”找回默认位置，“放大并操作”进入大棋盘。只读小图避免小落点误操作。
- **独立画中画**：支持Document Picture-in-Picture的浏览器可在网页之外打开独立小窗，直接按当前执色落子、停手；与主窗口、同伴实时同步。浏览器不支持或拒绝时自动使用页内悬浮图，并说明原因。小窗的实际位置由浏览器/系统管理；关闭小窗不会退出房间，离开房间/页面时自动关闭小窗。
- **房间聊天**：仅两个匿名座位可收发文字。Enter发送、Shift+Enter换行；中文输入法选词不触发发送。最多500字，发送过快会保留输入并提示稍候。文字不作为HTML、脚本或自动链接执行，无强制音效。

聊天最近50条仅在该服务进程内临时保留；刷新/重连同一房间可读最近记录，服务重启、重新部署后清空。聊天不写入棋谱、本机学习备份或公开列表，不上传本机进度、草稿、成员反馈。昵称与聊天需要通过联机服务器传给同伴；不要发送姓名、联系方式等个人信息。没有账号或公共聊天大厅。

回看是本页只读操作，不改变同伴棋局。真正悔棋仍须双方各执色确认；终局仍须双方确认死子清单后才计算面积胜负。本次没有新增通用死活判断。

旧服务器不带聊天能力时仍可下棋；聊天栏明确显示等待服务更新，不假装消息已送达。旧页面升级前先保存当前工作，再应用网站更新；不需要清除浏览器数据。
