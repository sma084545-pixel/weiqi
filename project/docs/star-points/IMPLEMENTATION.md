# 所有实际棋盘的星位

本增量以0.27.1-pages.1为唯一底本，程序版本0.27.2。星位只作方位参考，不属于棋子、题目答案或让子设置。

## 布局

统一数据源为 `src/core/board-star-points.ts`。内部坐标仍为从左上开始的row/col，显示坐标保持A–T跳过I、行数自下向上。

| 尺寸 | 显示布局 |
|---|---|
| 5路 | C3中央定位点；本项目小棋盘练习的显示选择 |
| 9路 | C3、G3、C7、G7及E5 |
| 13路 | D4、K4、D10、K10及G7 |
| 19路 | D/K/Q列与4/10/16行的九个交点 |

19路位置核对[BGA所载AGA规则的棋盘定义](https://www.britgo.org/rules/agarules.html)，访问日期2026-11-09。只参考星位坐标，不引入其中不同的贴目、停手、计分或重复规则。5/9/13路采用本项目上述明确显示约定，不宣称是统一官方小棋盘标准或固定让子规则。

## 共用实现

- `Board.tsx` 在交叉点按钮内绘制装饰性小圆点；直径随棋盘缩放，限制在3—7px，避免小窗中消失或盖住棋子。
- 星位为 `aria-hidden`、不可聚焦、`pointer-events:none` 的底层标记。原按钮的坐标说明、键盘路径、落子回调与禁着处理均保留。
- 棋子、最后一手、候选点、气环和目标标记覆盖底纹，不把星位写入board或markers。
- 数气、提子、摆棋、吃子小游戏、完整对弈、AI、联机、辅助下棋、教学示例、教师编辑和只读复盘快照都复用Board，因此同步呈现；悬浮小窗和原生画中画复用同一组件和样式。
- `file-exchange/graphics.ts` 的SVG/PNG/PDF使用同一位置表。裁切先从完整棋盘筛选，不以裁切中心建立假星位。正式题库和冻结材料文件未改。

装饰标记的可访问性与点击穿透参考本项目modern-web-guidance的accessibility/icons指南；本次未更新技能、项目依赖或锁文件。无新增远程依赖、上传、权限或收费资源。

## 更新与兼容

APP_VERSION与package版本提升到0.27.2，使原离线更新机制识别新构建。用户先保存，再在更新提示中应用新版本；无需清站点数据。数据库、内容schema、对局格式、超级劫历史、四档AI及三处服务地址不变。Render服务不需要因星位更新而重新部署。
