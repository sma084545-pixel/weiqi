# 复盘 → 续下 → 重试

在自由双人、完整围棋、普通 AI 或辅助下棋中，拖动已有棋局滑动条，点击“从这里继续”。联机棋局结束后，同一区域还有“AI 复盘”。复盘工作区独立打开，关闭后回到原页面及原来的滑动位置。

选择“自由继续”可选择现有四档真实 KataGo 对手；“辅助下棋继续”复用原有分级提示与事实反馈，默认使用可离线的本地教学伙伴，也可选择真实 KataGo。默认沿用你的执色；同屏双人没有个人执色，默认采用所选局面的行棋方，可自行改选。轮到对手时会先走；失败时保留局面，可手动重试，不会换成假 AI。

分支顶部标明“从第 X 手继续”。这是独立存档，不覆盖普通 AI 或辅助棋局，也不会向联机房间提交着法。“重新尝试当前分支起点”建立另一条尝试，保留之前分支；展开底部“已保存的独立分支”可恢复。本版每份原谱最多保存100条分支。刷新后从相同原谱重新打开工作区，可找回已存分支。浏览器的“离线与本机数据”完整备份也包含这些记录。

滑动条沿用项目的操作序号，包括落子、停手、认输、争议恢复和计分确认。复盘从0到最后一步均可继续。若该位置已结束，新分支撤除认输/计分确认；从双停确认局面恢复时，显式追加恢复对弈、清零连续停手，保留盘面、提子、轮次和位置超级劫历史。原棋谱及其终局结果保持不变。分支悔棋止于分支起点；更早局面仍可在原谱中选择。

## 联机赛后 AI 复盘

1. 本局正常结束后，点击棋盘下方“AI 复盘”。不需要创建新房间。
2. 自动巡检完整棋谱的气、实际提子、直接连接、脱离打吃等基础事实。报告以你的执色组织，不作能力或胜率排名。
3. 自动抽样统一使用现有标准 KataGo 复盘服务（不是极致模型），对最多两手的落子前/后局面进行抽样比较，最多4个请求，依次执行，不会全盘逐手耗费搜索。服务繁忙或失败时仍可看基础反馈、继续或导出报告；可取消和手动重试。
4. 点击“查看这一手”看落子后的局面；“重新尝试”严格回到该手之前。选续下方式后亲自换一个下法。

提子、连接等被列为可观察到的局部变化，不代表战略上一定最佳。一气棋只有在引擎核实合法提取时才说明可被立即提走；可能的弃子不能一概判错。KataGo 前后目差只是有限搜索的估计，界面注明抽样范围，不改联机胜负，也不自动裁判死活。

真实对手与引擎抽样需要网络。缓存准备后，本地战术巡检和本地辅助分支可以离线使用。更新前先保存/备份，通过既有“保存已提交内容并应用”升级，不清除站点数据。
