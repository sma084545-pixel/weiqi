# 能力边界

- 全盘自动核查仅覆盖基础战术事实。真实KataGo最多抽样4个局面，未逐手检索所有战略失误。搜索样本不是能力评级、确定损失或通用死活证明。
- 复用现有免费KataGo服务；可能冷启动、排队、限流或不可用。错误不换手、不改用模拟落子，不自动无限重试。本地辅助伙伴仍可用。
- 真实服务沿用1600项对局操作、256 KB请求上限；当前已精简为原始动作，常规长棋谱不再携带派生棋块数据。超过服务能力时可继续本地辅助分支，不能伪造或截断劫历史。
- 自由AI续下沿用已有服务贴目范围（-100至100，整数或半目）；超出时给出恢复说明，可用本地辅助分支继续。
- 每份原谱最多100条分支；保存受原有浏览器配额及单局序列化上限限制。写失败时原谱保留；请通过既有本机完整备份保留原谱与分支。
- 进行中的联机棋局不开放AI续下或复盘；赛后才进入独立练习，不向房间发送分支着法。本项目没有公开排名，复盘不新增排名。
- 原生Safari/Firefox、实体手机、屏幕阅读器、长期多人并发和真人教学尚未实测。触屏为浏览器模拟，不能冒称实体测试。
