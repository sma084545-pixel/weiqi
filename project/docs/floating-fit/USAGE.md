# 悬浮棋盘完整显示

程序0.21.3。原网址：https://sma084545-pixel.github.io/weiqi/#/play/online 。本机启动后网址仍为http://127.0.0.1:4190/#/play/online 。

打开“悬浮小棋盘”，5/9/13/19路均自动按小窗宽度和高度等比例排布，四角、全部边线和棋子同时可见，无需滚动查看另一侧。旋转屏幕、改变窗口大小或拖动小窗后仍显示整盘。独立画中画使用同一整盘适配。

轮到本人时直接点击空交叉点落子；终局确认时可点击整块标记/取消死子。主棋盘与同伴同步，回看历史仍为只读。顶部手柄用于拖动；键盘聚焦手柄后按方向键移动，聚焦棋盘后方向键导航、Enter/Space操作。

19路在很小的窗口中交点较密，需要更精细操作时点“放大棋盘”，普通/放大棋盘保留原来较大的点击区域。“复位小窗”将位置复位。悬浮盘优先保留完整全局视野，不再强制每格32px而裁掉其余棋盘。

已有网页先保存当前棋局，再点击“保存已提交内容并应用”；页脚版本应为0.21.3，不必清除站点数据。本轮只有前端变化，不需重新部署Render。免费房间/聊天仍为临时数据；规则、终局双方确认和本机保存方式保持。
