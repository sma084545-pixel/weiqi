# T01 独立预期，先于引擎实现

这些开发向量由本助手按用户规则逐点推导，不是人类教师审核。固定JSON在tests/fixtures/rules-vectors.json；运行时引擎不参与生成这些预期。

- 中心C3的四气为C4/B3/D3/C2；上边C5为B5/D5/C4；角A5为B5/A4。斜邻B4不与A5连成块。
- B4/C4/B3三子L形：正交空点为B5/C5/A4/D4/A3/C3/B2，共7；C3被两个子共用，仅算一次。
- single-capture在C4落黑，只提B4白；two-stone-capture在C3落黑，同时提B4、C4白；L形三白从两个邻点接触也只提3子一次。
- simultaneous-two-groups的白C4与B3互不正交连接，唯一共享气C3被黑占用后两块一并提走。
- capture-before-suicide：A5无直接空邻点，但B5白与A4白各只剩A5一气。黑落A5先提这两白，获得B5/A4两气，合法。
- suicide对照：仅白B5/A4时它们还各有其他气，黑A5不能提子且无气，拒绝，全部状态不变。
- merge把B3/D3用C3连接；前两块气之并集7点，落后整块8气。事件before/after分别给这两份集合，不由页面计算。

## 从空盘合法建立简单劫

完整5路，从黑开始依次B5、B4、A4、C5、B3、C3、E1、D4。八手均有气，盘面见JSON ko.before。第九手黑C4提白B4，新黑C4仅有B4一气；白立即B4回提会恰好重现第八手盘面，违反位置超级劫。
白先在E2打吃黑E1，黑D1连接回应；再白B4提黑C4。此时新增E2白和D1黑仍在盘上，因此不重现第八手盘面，回提合法。此前任何步骤不是手工灌入局面。

长距离重复另用明确的历史注入向量验证同一evaluatePlacement核：把某次合法候选落后盘面放在较早历史，而非只在最近两项。它必须拒绝SUPERKO。这只验证全历史检测，不称为由实际着法构成的长循环对局。完整GameState入口仍须重放，不接受这份人工注入史。

## 面积与终局

mixed完整5路：黑9子+C5一空=10；白9子+C1一空=10；A3–E3五空中立。空盘全部中立，即使贴目使数值有差也不创造领地。
dead-removal-assumption仅做明确假設计算：假定双方已同意移除中心C3白，黑外圈16子、内部9空，黑25，白加0.5贴目得0.5；不据此声称通用死活结论。原始中心白子和原始提子数均不改变。

同一盘面在未合法进入终局确认时只能preview。两停后的真实状态加双方相同标记才能confirmed；争议恢复保留盘面、轮次、上一手与完整重复历史，仅停手计数归零。吃子小游戏首提立即结束，两停无胜者，不进入面积确认。

## 状态与负例

每一成功事件可撤回并重做；比较棋局变量时revision单独作为递增文档版本，不回退。新分支成功事件清redo，拒绝事件不清redo。导入篡改captures/history/result/undoStack/redoStack任一项均应拒绝；改动开局贴目缓存应报KOMI_LOCKED。一个完全自洽的另写棋谱只能证明符合规则，不能证明是谁、何时或在哪所学校实际下过。
