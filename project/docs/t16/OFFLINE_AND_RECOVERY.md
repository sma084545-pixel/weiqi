# 教师离线准备与故障恢复

## 课前准备

1. 用 `pnpm preview`、localhost 静态服务或学校 HTTPS 地址打开应用。不要用双击 `file://` 代替。
2. 打开“教师视图 → 准备离线与备份”。确认“本机资料”显示 IndexedDB 已就绪。
3. 保持联网，点击“准备或重新核对离线资源”。只有标题变为“已可离线”，并显示缓存版本 0.16.0 与 7 项资源，才算准备完成。
4. 在浏览器开发工具或系统网络设置中真正断开网络，刷新本页并打开挑战题。应仍显示 30 道正式题可用。
5. 重新联网。导出一次完整备份，保存到教师能找到的位置。备份不含应用自带题库，因此体积只随本机记录增长。
6. 准备无设备替代材料。离线页可下载 `materials/t13/territory-counting-card.md`；其他纸面材料按活动实际选择。

## 更新流程

新版本安装完成但尚未接管时，页面显示“新版本已准备好”。它不会强制刷新。先保存当前题目、对局或讨论，再点击应用；程序会等待已提交的 IndexedDB 写入完成后才让新 Service Worker 接管。未保存到自动恢复会话的临时表单内容仍应先人工保存或导出。

## 常见故障

- **首次断网只看到恢复页**：这台设备没有完整缓存。重新联网，回到离线页，直到看到“已可离线”。
- **本机保存受限**：可能是隐私模式、浏览器策略、IndexedDB 被禁或空间不足。保留当前页面，尝试导出；再用普通窗口或释放空间。
- **备份无法导入**：保持现有数据不动。检查是否为 `LocalBackup`、schemaVersion 1、GO-CLUB-AREA-1；未知主版本需对应迁移工具。
- **迁移失败**：旧 localStorage 键不会在事务成功前删除。先导出可读取内容，保留原浏览器资料，再交给维护者检查。
- **更新等待**：关闭其他仍打开旧版应用的标签页，再重试检查更新。不要清浏览器数据来解决一般更新问题。

## 版本和隐私

版本号显示在离线页顶部，交接文件是 `handoff/T16.md`。全部记录留在当前浏览器；没有账号、默认上传或设备指纹。共享设备上的数据属于该设备的混合记录，不能称为个人测评。
