# 同屏双人吃子小游戏使用说明

从首页“我想找个伙伴玩”、学习路线第二阶段、提子实验室结束页或教师视图进入。开局首先显示“先提到棋子者获胜；这是入门小游戏”。默认使用完整9路棋盘，也可在开始前选择5路短练习。两位伙伴共同决定是否显示气辅助，再按“双方确认，开始本局”；开始后这些设置锁定并一直可见。

黑方先下，两人在同一设备轮流点击交叉点。屏幕同时写明当前执色和伙伴A/B；A/B只是座位标识，不要求真实姓名。一次合法落子首次提到一颗或多颗棋子时，该手立即结束本局并锁定盘面。非法点不会换手。双方若连续各停一手，本轮无胜者。页面没有倒计时、公开排名、面积得分或强制音效。

“显示气辅助”开启后会圈出当前棋块的气，适合第一次短局。它由共享规则引擎计算，并不是额外判胜条件。建议两人先一起决定是否使用；需要增加观察难度时，在下一局开始前关闭。

申请悔棋后，黑方与白方依次在同一设备确认。第一人确认时盘面不会变化；第二人确认后才准确撤回一手。任何一方按“拒绝”都保留原盘面、轮次、结果和历史。已结束的获胜手也可按相同步骤撤回，撤回后恢复可玩状态。

终局盘面继续显示。回看区最多列最后5手；上一步、下一步、播放回看和直接完成只切换保存的历史盘面，不产生新着法。提子结果还会说明哪一块在落子前只剩哪一口气。点击“交换黑白再来一局”会清空盘面、提子、着法、历史和结果，并交换伙伴A/B所执颜色。

“尝试完整9×9”现在显示已安装的T08说明和可用链接，可直接进入9、13或19路完整对弈。吃子小游戏的结果不会带入完整围棋。

键盘可用方向键移动棋盘焦点，Enter或空格落子；触屏只需轻触。手机上的9路盘在棋盘容器内局部滚动，页面本身不横向溢出。投影模式放大文字与棋盘点，系统减少动画设置会让回看直接到目标帧。
