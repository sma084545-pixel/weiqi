# 吃子小游戏变体说明

本模块使用 GO-CLUB-AREA-1 的 `capture-first` 模式。它保留轮次、交叉点、正交连接、去重气、先提对方再查己方、禁自杀和位置超级劫。停一手不参加重复检查，也不清空布局历史。

与完整围棋的区别只有明确的终止条件和界面用途：

- 一次合法着提到任意数量棋子，执棋方立即获胜；同一次状态转移写入结果，之后拒绝继续落子。
- 双方连续停手，本轮无胜者，可重开。
- 不进入死子确认或面积计分，不用提子数或面积决定本小游戏胜负。
- 默认9路、可选5路是本项目教学选择，不称为协会官方标准。
- 交换颜色重开建立新空盘和新历史；上局结果不累计，不形成积分榜。

黑胜、白胜与一手提两子的独立预期坐标写在 `tests/fixtures/t07-capture-game-expected.json`。它们在调用引擎前人工按规则顺序推导，再由测试重放。此范围证明固定案例和程序约定一致，不证明所有可能棋局的策略质量。
