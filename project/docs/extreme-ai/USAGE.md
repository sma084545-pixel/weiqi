# 极致模式使用方法

学习入口 → 与 AI 下一盘 → 难度选择“极致”。仍可选执黑/执白、5/9/13/19 路和开局贴目。只在新局设置时选难度，不在进行中的棋局静默换模型。

极致使用独立的较强模型，免费 CPU 的思考比原三档慢。等待时可以暂停；网络、启动或排队失败时棋局保持不变，可手动重试，也可先保存。未启用服务时会明确提示，不能开始，不借用旧三档冒充极致。

回退一手或最近回合、重做和棋局滑动条与原 AI 模式一致。回看历史局面只读，继续下棋先回当前手；刷新读取本机记录后 AI 默认暂停，避免自动产生额外一手。撤回或离开页面会取消未完成请求，旧回复不覆盖新盘面。

双停后人工确认死子和中立点，或一方认输后，才可主动“分析当前复盘局面”。极致对局的赛后分析仍使用同一模型，提供黑方视角的胜率、预计领先目数、候选与变化。这些是搜索估计，不替代双方确认的终局面积分，也不对应人类段位。

本机记录和题库仍按原方式保存。模型只收到主动对弈/分析所需的棋局起点、实际动作和贴目，不接收学习进度或反馈。无需账号、真实姓名或安装引擎。免费服务的休眠和额度限制见部署说明。
