# 已知限制与恢复

- 当前没有已知未解决的规则、数据或核心流程阻断。
- 极致采用适合免费CPU的官方tf2小模型，不能使用已实测OOM或超时的大模型；不声称是全网最强，不换算人类段位，也未做系统对局棋力标定。
- 普通9–19路样本约30–32秒。冷启动可能超过一分钟；若超时，原局保留，稍后手动重试。没有固定时延或并发承诺。
- 一活跃、一等待；每IP每分钟AI4次、复盘2次，全服务6次。繁忙或限流时保存后等待，不连续重试。免费额度共享，不保活，不自动付费或扩容。
- 原三档仍使用原小模型和8/24/64预算；极致故障不自动降级，也不影响本地棋谱浏览、真人对弈或已缓存教学。
- AI不自动裁定任意棋块死活。双停后人工确认，胜率和预计目差仅在结束后主动查看，不替代终局面积分。
- 0.25.1曾因发布顺序遗漏公开地址，0.25.2已修复并增加阻止漏配的保护。旧缓存先保存再应用更新，不清站点数据；若回滚旧程序，先导出极致续玩文件。
- 已测Chrome156与触摸/键盘模拟，未测原生Safari/Firefox、实体手机、长时多人满载或真人教学效果。Render私有日志/账单未读取，公开配额不是账单审核。
