## 实际命令与检查

在本材料目录的局部环境执行以下命令。RUNTIME变量来自CODEX_PRIMARY_RUNTIME；字体通过本目录Fontconfig与Skia注册，不装共享依赖。

```bash
python3 materials/micro-lessons/source/prepare-assets.py
"$CODEX_PRIMARY_RUNTIME_NODE" materials/micro-lessons/source/verify-content.mjs
"$CODEX_PRIMARY_RUNTIME_NODE" materials/micro-lessons/source/build-lessons.mjs
"$CODEX_PRIMARY_RUNTIME_PYTHON" materials/micro-lessons/source/build-teacher-summary.py
# 字体环境：FONTCONFIG_FILE=$PWD/materials/micro-lessons/build/fontconfig.xml
"$CODEX_PRIMARY_RUNTIME/dependencies/bin/override/soffice" \
  -env:UserInstallation="file://$PWD/materials/micro-lessons/build/lo-profile-final" \
  --headless --convert-to pdf --outdir materials/micro-lessons/output \
  materials/micro-lessons/output/*_r1.pptx
"$CODEX_PRIMARY_RUNTIME_PYTHON" materials/micro-lessons/source/render-pdfs.py
"$CODEX_PRIMARY_RUNTIME_PYTHON" materials/micro-lessons/source/verify-delivery.py
bash -n materials/micro-lessons/source/rebuild.sh
python3 -m py_compile materials/micro-lessons/source/author-lessons.py \
  materials/micro-lessons/source/prepare-assets.py \
  materials/micro-lessons/source/render-pdfs.py \
  materials/micro-lessons/source/verify-delivery.py \
  materials/micro-lessons/source/build-teacher-summary.py \
  materials/micro-lessons/source/package-final.py
python3 materials/micro-lessons/source/package-final.py
```

PPT生成内部执行结构、字体/几何检查和Artifact Tool回读，每份实测报告留在qa/T22_*.validation.json。全项目程序构建/测试不属于本材料支线，未执行或声称通过。本次没有另写规则引擎。视觉检查逐页查看25页主讲和5页摘要，不只抽样封面。独立版每页亦渲染并与合并逐页对照。
