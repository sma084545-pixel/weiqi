`bundle.json` 只含原封闭 schema 的 Puzzle／TerminalFixture。标题、常见错误、同伴讨论等教学字段通过既有 assumptions／explanation 保留，并由 `pedagogy.json` 按相同 ID 补充；后者不按 ContentDocument 导入。无需 schema 迁移。
